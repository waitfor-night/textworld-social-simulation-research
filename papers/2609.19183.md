# Message capacity and claim wording set the transition points of collective truth-finding in language-model networks

- **标识符：** arXiv:2609.19183
- **作者：** Makoto Fukushima
- **日期 / 版本：** 2026-09-15，版本 1

- **观察日期：** 2026-09-18
- **置信度：** `high`

## 一句话要点

论文把“每个 agent 只读少数消息”的阅读上限建模为 message capacity，发现集体真值发现的转折点同时由该上限和 claim 措辞设定的阈值决定。

## 研究对象

- **世界或环境：** 由 message capacity 生成的通信网络，31 个来源、8B 与 70B 模型。
- **智能体：** 只读取有限 inbox 的 LLM agents。
- **观察与动作：** 消息集合、claim 措辞、单 agent 判断与集体结果。
- **目标与交互协议：** 31,824 次随机查询加 1,414 个指定初值的 episode。

## 论文做了什么

将单 agent 判断拟合为 inbox 加权和的 logistic 函数，再据此预测集体错误共识是否可达，并把预测与实际 episode 结果对照。

## 证据与发现

作者报告原本的预测在实验中失败：即使 75% agent 初始正确，正确方也只在 28–45% episode 中胜出；引入 claim 自身的 wording threshold 后同权重可复现结果，反向措辞显示阈值跟随断言内容而非真假。

## 可复用模式

社会扩散模型必须分开测量单 agent 的 claim threshold 与消息容量，两者共同决定集体转折点。

## 局限性与开放问题

结果基于两个 8B 模型和部分 70B 检查；wording bias 在不同规模下表现不同。
