## 一句话要点

论文提出按时间尺度分层、以 tick 为自主行动单位、并在 review 失败后升级模型的长期 agent 架构，认为持续学习需要生存期超过任何 context 的基底。

## 研究对象

- **世界或环境：** 跨天或跨周的运维修复与研究计划类任务。
- **智能体：** 每层维护下层 bounded 摘要文件并周期性 review 的 agent harness。
- **观察与动作：** 层级摘要文件、tick 触发的行动、escalation 与 review 结果。
- **目标与交互协议：** 十天 campaign 中复现已发表强化学习结果，人每天只介入一次。

## 论文做了什么

从长期设置推导七个瓶颈，用三层结构回应，并报告跨 context reset 与 session boundary 的连续性。

## 证据与发现

作者报告 agent 在所有 context 重置和会话边界后仍保持主线，早期写入的操作知识在模型权重不变的情况下改变后续行为。

## 可复用模式

长期世界运行应把操作知识写入独立于进程的持久基底，并把 harness 已有的检查点作为学习入口。

## 局限性与开放问题

单次十天 campaign 不足以确立一般性；持久文件的冲突与陈旧处理未充分评估。
