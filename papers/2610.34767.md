## 一句话要点

科学 agent 面对更严格的问题：正确记住的事实未必**有资格**被使用——同一个测试结果，在结局与停止规则事先固定时支持确证，而在从二十个被检验结果中挑选出来时只支持探索。

## 研究对象

- **世界或环境：** scientific evidence whose eligibility depends on pre-specified outcomes
- **智能体：** SciValidityBench over agent memory systems
- **观察与动作：** 被记住证据在既定状态下是否有资格影响决策。
- **目标与交互协议：** 提出 scientific use validity 概念，并构建 SciValidityBench 检验记忆是否满足该资格条件。

## 论文做了什么

提出“科学使用有效性”与 SciValidityBench，把记忆资格从“是否记得”推进到“是否可用”。

作者指出多数记忆基准把长期记忆当检索问题，而科学 agent 的问题更严（具体数值需核对正文）。
