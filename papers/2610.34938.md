## 一句话要点

编码 agent 能依据先前任务经验调整自己的 harness（软件、配置与指令），但这些调整是否真的改善后续任务仍不清楚。

## 研究对象

- **世界或环境：** 30 SWE-bench Verified issues with 125 retrospective proposals
- **智能体：** Claude Code with a retrospective skill;24 changes implemented
- **观察与动作：** agent 回顾已完成会话后提出的 harness 修改建议，以及实施后的重复劳动变化。
- **目标与交互协议：** 研究 etro 这一技能：让 agent 回顾会话并提出 harness 修改；在 30 个 SWE-bench Verified 问题上运行 Claude Code，对 **125 条建议**做质性编码，实施其中 24 条并评测。

## 论文做了什么

对编码 agent 的 harness 自我演化做实证研究，统计建议类型并检验实施效果。
