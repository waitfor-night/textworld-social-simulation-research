## 一句话要点

世界模型提供可复用的规律，因而可以减少每条经验必须存储的信息；存储分配应以“重构误差的下游影响”对照存储成本。

## 研究对象

- **世界或环境：** five long-term agent memory benchmarks
- **智能体：** memory conditioned on shared world-model predictions
- **观察与动作：** 共享预测、被压缩保留的信息，以及被省略内容的重构。
- **目标与交互协议：** 把“以世界模型为条件的记忆分配”形式化，提出 MemoWM：用共享预测压缩保留信息并重构省略内容，任务感知的分配规则在重构误差的期望影响与存储成本之间取舍。在五个长期 agent 记忆基准上评测。

## 论文做了什么

主要贡献是把“以世界模型为条件的记忆分配”形式化，并提出 MemoWM 的共享预测压缩与任务感知分配规则。

## 证据与发现

作者报告平均答案准确率 42.42%，比最强基线高 2.62 个百分点，同时相对最省存储的基线 MIRIX 把平均经验专属存储降低 53.9%；进一步分析显示更强的世界模型在同等任务质量下降低每条经验的存储量（计入模型参数后存在权衡）。

## 可复用模式

记忆与预测能力是可以互换的资源：先明确世界模型已能预测什么，再决定记忆里还该留什么。

## 局限性与开放问题

基准为长期记忆问答类任务；存储—参数权衡意味着总成本不一定下降。

## 与本索引的关系

把 Text World Model 的能力与记忆设计直接挂钩：预测能力越强，需要逐条记录的内容越少。
