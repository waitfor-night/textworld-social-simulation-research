## 一句话要点

论文把长寿命 NPC 的推理缓存视为需维护的历史状态，在 true sequence tail 更新记忆以避免过期事实导致确定性游戏规则输入错误。

## 研究对象

- **世界或环境：** 多轮游戏 NPC 对话和八轮脚本化记忆维护。
- **智能体：** 本地量化 Qwen 混合 recurrent–attention 角色模型。
- **观察与动作：** superseded memory、KV entries、recurrent state 和角色回答。
- **目标与交互协议：** 比较 true-tail update、full refill 与 slot-preserving 替代方案。

## 论文做了什么

运行时删除被替换 KV，在真实序列尾计算新记录，并保留未改变 KV 与持续 recurrent state。

## 证据与发现

作者报告 true-tail 更新保持当前状态和历史绑定；slot-preserving 方案会重复 double-subtraction error，单纯 attention 分布相近不能解释语义正确性。

## 可复用模式

NPC memory 更新必须遵守时间顺序和替代关系；缓存状态不能被当作可随意拼接的文本块。

## 局限性与开放问题

实验限于单一量化模型和脚本场景；多角色共享记忆及崩溃恢复未覆盖。

## 与本索引的关系

把角色连续性连接到本地运行时和权威游戏状态，是文本世界实现层的重要补充。
