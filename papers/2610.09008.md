## 一句话要点

持久记忆会把推理中的“曾经考虑过”变成日后的“事实”：一段被否决的计划、一次模拟的工具结果、别人的信念，只要句子被留下就会重新进入决策。

## 研究对象

- **世界或环境：** long-term memory across conversations
- **智能体：** LLM memory with scope-aware commit rules
- **观察与动作：** 命题被写下时的语境：属于哪个世界、哪条分支、哪一位说话者。
- **目标与交互协议：** 识别 discourse ownership 作为丢失的语境，并给出 CASK 之类的因果化 commit 规则，决定哪些内容有资格写成记录。

## 证据与发现

作者报告语言模型内部已带有对 ownership 有因果作用的信号，而常规记忆接口在把推理转成记录时把它丢掉了——这是“反直觉”的第一发现，具体测量需核对正文。

## 可复用模式

记忆写入必须带上“谁在什么语境下说的”，否则被否决的候选会以事实身份复活；这与 ActionRequest≠事实的原则同源。
