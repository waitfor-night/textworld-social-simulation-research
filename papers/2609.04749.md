# DCFA: Dual-view Causal-inspired Attribution for Failure Reasoning in LLM-based Multi-agent Systems

- **标识符：** arXiv:2609.04749
- **作者：** Zehao Wang, Lanjun Wang, Shilong Jin, Junjie Chen, Yanghua Xiao

- **主领域：** EVAL — 多智能体失败归因
- **相关性：** `core`
- **标签：** `multi-agent;failure-attribution;causal-analysis;counterfactual;trajectory;reproducibility;benchmark`
- **观察日期：** 2026-09-09
- **置信度：** `medium`

## 一句话要点

DCFA 用全局依赖图定位最早的决定性错误，再用局部反事实式搜索细化归因，针对长多智能体轨迹中的表面错误和上下文退化。

## 研究对象

- **世界或环境：** Who&When 失败归因基准，含由 CaptainAgent 生成和人工整理的多智能体执行轨迹，任务来自网页导航与通用助理场景。
- **智能体：** 产生原始轨迹的多智能体系统，以及负责读取轨迹并归因的 LLM 分析器；DCFA 本身不训练专用参数。
- **观察与动作：** 分析器读取按步骤记录的消息、工具结果和错误，构建候选依赖图并对局部链条进行反事实式验证。
- **目标与交互协议：** 找出最早一个被纠正后可逆转系统失败的 decisive error，以 step-level accuracy 与多种提示归因基线比较。

## 论文做了什么

DCFA 由 Global Causal-inspired Attribution（GCA）和 Local Counterfactual-inspired Enhancement（LCE）组成。GCA 从完整轨迹抽取交互依赖，LCE 只在关键子轨迹上做双向扩展和修正；实验覆盖 Who&When 的 184 条轨迹、六个 LLM 和五种基线。

## 证据与发现

作者报告 DCFA 在六个模型上相对强基线最高提升 8.27 个百分点的 step-level accuracy；在其表格中，加入 LCE 会进一步提高长手工轨迹的归因表现，但运行时间和 token 消耗也显著增加。结果是提示驱动的归因实验，不等于真实因果识别。

## 可复用模式

- 定义“可逆转失败的最早动作”而非只找最后一个异常；
- 将全局轨迹摘要与局部依赖链分开，缓解长上下文退化；
- 报告步骤级定位、运行时和 token 成本，避免 agent-level 指标掩盖错误位置。

## 局限性与开放问题

基准只有 184 条轨迹，标签和依赖图仍由数据与 LLM 判断定义；更长、更开放的社会模拟轨迹可能超出上下文或推理能力。反事实式文字验证也不能替代可执行系统中的真实重放干预。

## 与本索引的关系

DCFA 为 `Trajectory`、`Replay` 和评估审计提供失败定位接口，可与 trajectory-judge、ClaimReceipt 及世界状态回放工作结合。
