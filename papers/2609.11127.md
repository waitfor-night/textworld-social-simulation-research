## 一句话要点

KuaiRP 用角色模板、用户行为模拟、规则奖励和两阶段 on-policy distillation，在注入领域世界知识后恢复被损害的通用 agent 能力。

## 研究对象

- **世界或环境：** 专用角色扮演对话及通用 agent 任务。
- **智能体：** 小参数 KuaiRP 系列模型。
- **观察与动作：** 角色 profile、领域设定、多轮对话和通用任务输出。
- **目标与交互协议：** 同时评估角色保真、语言质量和通用能力保持。

## 论文做了什么

训练流程包含标准角色模板、SFT 数据构造、规则复合奖励，以及以领域模型为教师、原始基座为学生的两阶段蒸馏。

## 证据与发现

作者声称目标领域角色保真可匹配专有前沿模型，同时恢复通用 agent 能力并保持低部署成本；开放 artifact 仍有限。

## 可复用模式

角色训练后必须重测通用行动能力，并将领域知识、风格与 agent 能力分别报告。

## 局限性与开放问题

技术报告由模型团队自评，模型、数据和完整训练代码的可复现性尚不清楚。

## 与本索引的关系

延伸 RoleLLM、Character-LLM、CoSER 与 HER，突出角色知识注入和通用能力遗忘之间的权衡。
