## 一句话要点

长程编码中，仓库变化会让早先的执行证据失效；记忆需要在复用前对齐到当前任务与仓库状态。

## 研究对象

- **世界或环境：** multi-file long-horizon coding tasks
- **智能体：** coding agents with provenance-aware memory
- **观察与动作：** 以文件等关键信息为锚点的不可变 memory trace，以及任务与仓库状态的演变。
- **目标与交互协议：** 把历史存成不可变 trace，并检验其在上下文刷新后能否重建一致的任务状态、以及被召回证据是否仍然有效。

## 论文做了什么

主要贡献是不可变 trace 的设计，以及上下文刷新后状态重建与召回证据有效性的检验。

## 证据与发现

作者指出既有方法（更大窗口、压缩、检索、仓库表示）常无法在上下文刷新后重建一致状态或验证被召回证据的有效性。摘要未报告具体指标数值。

## 可复用模式

与 MemTrace 的取向一致：证据需要锚定到它所依据的产物版本，否则“记得”不等于“仍然有效”。

## 局限性与开放问题

面向编码 agent 场景；机制描述为主，摘要缺少对照结果。
