## 一句话要点

该文直接搜索紧凑、可编辑的反应式角色程序，以符号枚举完成局部策略槽，并让 coding agent 只提出高层 policy sketch。

## 研究对象

- **世界或环境：** 14 个连续空间游戏，涵盖经典控制与多智能体足球。
- **智能体：** 由领域专用语言表达的反应式游戏角色策略。
- **观察与动作：** 几何状态、方向选择与连续游戏动作。
- **目标与交互协议：** 设计者给定 reward；比较纯枚举、单独 coding agent 与 agentic sketching。

## 论文做了什么

设计含 direction maximization 等高阶构造的 DSL，并用 synthesis antipattern 排除冗余程序；组合 coding agent 的高层草图和 bottom-up enumerator 的局部补全来搜索策略。

## 证据与发现

作者报告纯枚举通常比单独 coding agent 更高效，而组合方法显著优于两者；生成策略紧凑、可读、可编辑并能跨任务使用。论文计划发表于 SIGGRAPH Asia 2026；当前未确认代码与逐任务数值。

## 可复用模式

将角色的有后果行为表示为受限、可执行政策，而非让自然语言直接控制世界；LLM 负责提出结构，确定性搜索或验证器负责补全和检查。

## 局限性与开放问题

任务以连续几何反应为主，不涉及 persona、信念、记忆或语言互动；reward 由设计者提供。它支持行为层的可解释性，但不证明角色身份保真。

## 与本索引的关系

为最小主动角色的 `ActionIntent → executable policy` 提供相邻证据，并与 GameLogicBench 的 tick-level 规则检查形成生成—验证配对。
