## One-line takeaway

CHIME separates planning and execution memories and assigns credit before writing, reducing the chance that a failed action teaches the planner the wrong lesson.

## Research object

- **World or environment:** Four long-horizon agent benchmarks with multi-step plans and tool or environment execution.
- **Agents:** A self-evolving LLM agent with a planning memory bank, an execution memory bank, and a controller that attributes outcomes.
- **Observations and actions:** The agent records plans, executions, task outcomes, and attribution judgments before retrieving memories for later decisions.
- **Goals and interaction protocol:** Improve future planning without parameter updates while keeping planning errors distinct from execution or environmental failures.

## What the paper does

CHIME applies an attribute-before-memorize rule: each outcome is assigned to the plan, the execution, both, or neither, and only the relevant memory bank is updated. The paper compares this hierarchy with training-based and self-evolving memory baselines and studies transfer across backbones.

## Evidence and findings

The authors report consistent gains on four long-horizon benchmarks, including average gains of 2.96 and 3.68 points in the listed comparisons, 129 retained memories versus 3,585 for a baseline, attribution agreement up to 97.9%, and transfer across backbone models. The arXiv record says code will be released; the related Marco-DeepResearch repository did not expose a CHIME-specific implementation during this recheck, so the reported comparisons and attribution labels remain unreplicated author claims.

## Reusable patterns

- Attribute outcomes before persisting experience, instead of using a single success bit.
- Keep plan provenance separate from execution traces and environmental disturbances.
- Measure memory utility and transfer, not only the number of retained items.

## Limitations and open questions

Attribution itself may be noisy or biased, especially when social outcomes have delayed and interacting causes. Benchmark details, code, and the behavior of the banks under changing norms or hidden-state leakage need inspection; no social-world evaluation is reported.

## Relation to this map

CHIME gives the map a precise credit-assignment rule for social memory. It can be combined with invalidation contracts and belief boundaries so a remembered norm records both why it was useful and when it should stop applying.
