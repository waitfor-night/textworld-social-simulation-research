## 一句话要点

代码世界模型用显式状态与可执行规则表示世界动态；关键在于让对象表示、行为修订与视觉记忆围绕同一批对象组织，从而使后续观察以最新状态与相容外观为条件。

## 研究对象

- **世界或环境：** text prompts describing interactive objects and rules
- **智能体：** coding agent planning object structure properties and rules
- **观察与动作：** 提示中推断出的对象交互需求、对象结构/属性/规则，以及白箱对象的纹理记忆。
- **目标与交互协议：** 编码 agent 从提示推断对象交互需求，联合规划对象结构与规则；世界按规则演化，用户动作可转向，文本请求可编辑属性或扩展能力且保留未受影响的状态；程序推进世界状态，生成式渲染器把当前结构与记忆中的外观结合。

## 论文做了什么

提出 Mallea：一个从文本构建、转向与记忆世界的系统，把对象表示、行为修订与外观记忆统一在同一批对象上。

## 证据与发现

作者强调对象纹理记忆只对白箱定义的对象保留可复用外观，并随对象变化而适配；摘要未给出量化结果。

## 可复用模式

与本项目 World 的对象能力（inspect/take/use 挂在对象上）几乎同构，并补上两块：状态修改后未受影响部分必须保留，以及“渲染”与“规则”分离。

## 局限性与开放问题

以视觉渲染为输出端的代码世界；文本世界的“外观记忆”对应物尚未定义；摘要缺少量化评测。

## 与本索引的关系

与 RoleWorld 的功能角色抽象同属代码世界模型，但更强调“构建—转向—记忆”的连续编辑。
