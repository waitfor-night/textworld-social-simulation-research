## 一句话要点

不同记忆需要不同处理策略，用统一检索策略会次优；作者构建带类型标注的数据集并训练路由器自适应识别记忆与查询类型。

## 研究对象

- **世界或环境：** topic-rich multi-scenario memory settings
- **智能体：** router model over memory and query types
- **观察与动作：** 记忆条目与查询的类型标注，以及路由器选择的处理策略。
- **目标与交互协议：** 发布 TriMEM 记忆多分类数据集，为跨场景的记忆类型提供精确标注；在此之上提出 MemoType 框架，用学习的路由器同时识别记忆与查询类型并按类型检索。

## 证据与发现

作者指出记忆场景话题丰富、情境复杂、边界模糊，精确分类并不容易，因此先构建标注数据集再训练路由器。摘要未报告具体指标数值。

## 可复用模式

“记忆该按类型分别处理”是一个可检验的假设；若成立，角色记忆也需要按内容类型（事实/偏好/情境）走不同策略。

## 局限性与开放问题
