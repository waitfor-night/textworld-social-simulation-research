## 一句话要点

GAUGE 检查 persona 用户模拟器加 LLM judge 的离线排名是否与环境可验证任务成功一致，并区分排名有效性与构念有效性。

## 研究对象

- **世界或环境：** τ²-bench 与 SimulatorArena 的任务型交互。
- **智能体：** 六个 provider 的 25 个候选 agent、persona user simulators 和 LLM judges。
- **观察与动作：** 模拟对话、满意度评分和环境可验证 reward。
- **目标与交互协议：** 比较离线 judge gate 与 grounded reward 的模型排序。

## 论文做了什么

协议分别测 ranking validity 与 construct validity，避免把 judge 一致性误认为所测构念正确。

## 证据与发现

作者报告满意度对任务成功几乎没有信息，即使模拟用户表示满意也可能没有完成任务，说明低成本离线 gate 可选择错误 agent。

## 可复用模式

LLM judge 必须与环境 reward 校准；分别报告排名相关性、任务成功和用户体验。

## 局限性与开放问题

结果来自两个 benchmark 和特定用户模拟器；真实用户体验不等同于程序化成功。
