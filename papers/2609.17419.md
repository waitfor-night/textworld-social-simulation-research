## 一句话要点

论文把 agent 隐含状态与 benchmark 权威状态对齐，发现局部动作仍然有效时，全局状态保真度可能已经崩溃。

## 研究对象

- **世界或环境：** 受控谜题、工具使用、具身任务、多跳检索、通用助手推理和 Game of Life。
- **智能体：** 长程 LLM agents。
- **观察与动作：** 观察、行动、工具调用和中间 belief trajectory。
- **目标与交互协议：** 22 项实验，以显式 null model 测压力、错误 avalanche、依赖和 belief transition。

## 论文做了什么

比较 agent-implied state 与 benchmark-grounded state，并从 self-organized criticality、weak chaos 和 metastability 三种动力学视角分析误差传播。

## 证据与发现

作者报告局部合法动作可在全局状态失真后持续，压力会引发突然崩溃，错误序列有长记忆；但不支持普适幂律、统一临界点或共同最优干预等更强主张。

## 可复用模式

逐步记录 agent belief 与 authority state 的差异，测局部—全局 mismatch 和错误传播，而非只看终局 reward。

## 局限性与开放问题

动力学类比依赖状态对齐和 null model；多任务结果不等于统一自然规律。

## 与本索引的关系

为文本世界模型增加 trajectory-level state-fidelity 诊断，并强化 Authority 与 Belief 分离。
