## One-line takeaway

LOCOMO-CONV shows that memory systems that look strong on explicit question answering can fail when useful context is only implied by a live conversation.

## Research object

- **World or environment:** Multi-turn conversational episodes derived from LoCoMo.
- **Agents:** Conversational agents paired with five representative memory systems.
- **Observations and actions:** The agent retrieves or elaborates memory while responding to dialog, implicit, counterfactual, or composed queries.
- **Goals and interaction protocol:** Measure both retrieval recall and end-to-end response quality in situ rather than probing memory with isolated questions.

## What the paper does

The benchmark adds four query styles and auxiliary `supportive_memory` annotations for context that helps a response but is not the gold fact. It compares raw-turn and abstractive memories, with and without multi-facet query rewriting.

## Evidence and findings

The authors report substantial gaps on implicit and composed queries. Rewriting improves raw-turn retrieval but not abstractive memory, and high retrieval scores do not guarantee better responses. They identify “silent grounding,” where memory improves contextuality without an explicit fact mention.

## Reusable patterns

- Evaluate memory inside the dialogue policy, not only with QA recall.
- Distinguish evidence that must be stated from context that should quietly shape an answer.
- Keep query style and conversational framing as controlled benchmark variables.

## Limitations and open questions

The benchmark is derived from conversational data rather than an embodied social world. It does not by itself test privacy boundaries, agent-to-agent memory sharing, or whether implicit grounding changes downstream actions.

## Relation to this map

LOCOMO-CONV provides a practical evaluation layer for role-playing and social agents: relationship and norm memories should be tested under indirect cues and measured for both helpful grounding and inappropriate leakage.
