## 一句话要点

论文主张多智能体优势受任务结构约束：长程且依赖稀疏时有系统收益，紧耦合顺序流程中单 agent harness 更优。

## 研究对象

- **世界或环境：** 长程复杂任务 benchmark。
- **智能体：** 单 agent harness 与基于 SAIGE 的动态协作图。
- **观察与动作：** 按需生成的 agent 节点、语义依赖边与上下文开销。
- **目标与交互协议：** 比较协作规模、递归深度与任务表现的关系。

## 论文做了什么

分析多智能体协作相对单 agent 的能力边界，并提出语义感知的增量图演化机制。

## 证据与发现

作者报告扩大 agent 池或加深递归并不持续改善结果；收益取决于任务依赖结构而非 agent 数量。

## 可复用模式

协作拓扑应由任务依赖推导，而非默认全连接或固定层级；报告成本与任务结构一并给出。

## 局限性与开放问题

摘要信息有限、缺少公开代码；结论依赖所选 benchmark 的依赖结构分布。
