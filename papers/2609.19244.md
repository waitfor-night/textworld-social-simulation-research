## 一句话要点

论文用真实用户交互与受控查询结合的方式，端到端刻画四个会话平台中 agentic search 的决策、策略、来源与回答。

## 研究对象

- **世界或环境：** ChatGPT、Claude、Grok、DeepSeek 四个会话平台的搜索流程。
- **智能体：** 带 Web 搜索能力的会话 LLM agents。
- **观察与动作：** 是否搜索、查询改写、来源选择、结果使用与最终回答。
- **目标与交互协议：** in-vivo 真实交互加受控查询的混合观测。

## 论文做了什么

沿搜索生命周期采集决策与结果，并跨平台比较策略与回答特征。

## 证据与发现

作者报告 agentic search 各阶段行为在平台间存在系统差异；观测以描述性刻画为主，未建立质量因果归因。

## 可复用模式

外部信息进入社会模拟或 agent 决策前，应记录检索决策、来源与使用方式，而非只保留最终回答。

## 局限性与开放问题

平台黑盒、快照随时间变化；in-vivo 观测缺少随机化。
