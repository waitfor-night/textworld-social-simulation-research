## 一句话要点

LSREP 用有序重放、生命周期计划、重复 probe 和动态参考答案评测记忆，且主动报告其 ICE v2 case study 在公共基准上显著弱于 vector-RAG。

## 研究对象

- **世界或环境：** 私有单用户记忆流与公开 LongMemEval diagnostic。
- **智能体：** ICE v2 local-first memory middleware 和 vector-RAG baseline。
- **观察与动作：** 1,985 turns、219 probes、52 checkpoints 和 1,211 probe-checkpoint observations。
- **目标与交互协议：** 测状态如何累积、老化和吸收修订，并审计机制是否真正被执行。

## 论文做了什么

协议结合 ordered replay、explicit lifecycle、repeated probes、evolving references 和 mechanism-fidelity checks，再以 ICE v2 为案例。

## 证据与发现

作者报告普通密度数据上 ICE v2 与 vector-RAG 质量近似但 token 更多；LongMemEval 上 evidence-only 为 50.8% 对 72.8%，full-S 为 43.0% 对 69.5%。审计还发现检索缺陷和未被执行的机制。

## 可复用模式

记忆 benchmark 保存 checkpoint 和当时正确答案；同时验证声称的机制是否在轨迹中实际触发。

## 局限性与开放问题

私有数据规模有限，ICE v2 不是协议本身；缺少公开实现会降低复现性。
