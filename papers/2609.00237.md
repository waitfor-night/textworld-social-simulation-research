## One-line takeaway

Gated-Memory Routing turns execution history into a learned compact state that chooses the next role or backbone and halts when the retained evidence is sufficient.

## Research object

- **World or environment:** Five reasoning and code-generation benchmarks with multi-step agent execution histories.
- **Agents:** Multiple specialist roles and backbone models coordinated by a router, memory write gate, retrieval gate, and halting controller.
- **Observations and actions:** The system observes query plus prior execution, writes non-redundant steps, retrieves a relevant subset, selects the next role/model, and can stop.
- **Goals and interaction protocol:** Preserve useful progress while avoiding the cost and noise of replaying every prior step.

## What the paper does

The method learns when to write an execution step, which memories to expose to each agent, and when enough evidence has accumulated to terminate. It compares this adaptive state against query-only and full-history routing baselines.

## Evidence and findings

The authors report the best average accuracy across five benchmarks, a 2.44-point improvement over the strongest baseline, and a 31.9% HumanEval inference-cost reduction. The arXiv record links a repository and notes EMNLP 2026 acceptance, but the repository did not expose an implementation during this recheck; all performance numbers remain author-reported.

## Reusable patterns

- Treat memory writes and retrieval as explicit routing decisions with observable gates.
- Log what was omitted as well as what was retained, especially for socially important facts.
- Couple a stopping rule to evidence sufficiency rather than a fixed turn budget alone.

## Limitations and open questions

The evaluation is reasoning- and code-centric, so it does not establish preservation of relationships, norms, or private beliefs. Learned gates may systematically drop low-frequency but safety-critical context, and routing-induced role hierarchies need provenance and fairness checks.

## Relation to this map

This is a transferable orchestration pattern for multi-agent text worlds. It complements the map's credit-aware and invalidation-based memory records by making retention, retrieval, and termination measurable control surfaces.
