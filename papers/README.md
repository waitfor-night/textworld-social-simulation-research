# Papers

`index.csv` is the machine-readable inventory. Long-form notes use the template in [`../templates/paper.md`](../templates/paper.md) and should be named with a stable identifier, for example `2401.01234.md`.

Recommended `index.csv` columns:

`id,title,first_author,year,version,primary_area,relevance,tags,environment,agents,evaluation,code_url,canonical_url,observed_on,confidence,note_file`

Use one row per work, not one row per version. Put version changes in the note file.
