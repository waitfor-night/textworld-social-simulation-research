## 一句话要点

CoALA 用模块化记忆、内部/外部结构化动作空间和通用决策循环统一描述语言智能体，把近期 prompt scaffold 放回认知架构与符号 AI 的历史中。

## 研究对象

- **世界或环境：** 广义外部环境以及代理内部记忆空间。
- **智能体：** 由语言模型、模块化记忆和决策过程组成的 language agents。
- **观察与动作：** 外部感知、对环境的动作，以及读取、写入和推理等内部动作。
- **目标与交互协议：** 用统一架构回顾现有系统，并指出可操作的研究方向。

## 论文做了什么

论文提出 Cognitive Architectures for Language Agents，将工作记忆、长期记忆、决策循环和结构化动作空间结合，回顾 ReAct、Generative Agents 等系统如何落在该框架中。

## 证据与发现

主要贡献是分析框架和文献组织，不是性能 benchmark。它能精确比较模块和信息流，但不证明采用更多认知模块必然提高任务或社会有效性。

## 可复用模式

- 区分内部记忆动作与外部世界动作；
- 明确决策循环读写哪些状态；
- 按信息流而非 prompt 文件数量描述 agent 架构。

## 局限性与开放问题

CoALA 抽象层较高，不规定权威环境、权限、并发提交或宏观事件机制。认知术语与工程模块之间也并非一一对应。

## 与本索引的关系

CoALA 为 Role Agent Engine 的模块边界提供分析语言，也可用于比较当前索引中的长期记忆、规划和工具代理工作。
