## 一句话要点

BenchShield 用评测生命周期模型、静态污点分析和运行时基础设施证据，判断 agent 是否越过预期评分边界。

## 研究对象

- **世界或环境：** 三个交互式 agent benchmark 的工作区、工具、提交物和评分过程。
- **智能体：** 被评测 agent 与基础设施侧检测器。
- **观察与动作：** 静态奖励路径、运行时事件和 reward-relevant trajectory。
- **目标与交互协议：** 对 31,000 多次公开运行中的 456 条人工裁决轨迹评估检测。

## 论文做了什么

有限状态生命周期模型定义合法评测边界；静态分析预找路径，运行时分析用基础设施证据归因具体利用。

## 证据与发现

作者报告 full-chain recall 从基线的 23–94% 提高到 77–100%，成本最高降低 65%；运行时 reward-hacking 检测准确率为 96%。

## 可复用模式

评分器、工作区和提交生命周期必须进入审计日志；检测依据环境证据而非代理自述。

## 局限性与开放问题

模型覆盖不到的生命周期事件仍可能漏检；结果来自三个 benchmark，不能视为通用安全保证。
