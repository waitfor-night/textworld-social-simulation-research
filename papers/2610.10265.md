## 一句话要点

用最终答案对错评价个人记忆，会掩盖生成之前就已发生的三类失败：值过期、归属错人、以及截止前没有可用事实。

## 研究对象

- **世界或环境：** controlled revision benchmark with personal facts
- **智能体：** retrievers sharing an active store
- **观察与动作：** 记忆块中的值及其时态有效性、归属对象，以及服务截止时间之前是否存在有用事实。
- **目标与交互协议：** 以 Personal Fact Memory 为参照层，直接测量上述失败；在受控修订基准上比较“只服务每个正确键控槽位的活跃值”与不做更新消解的情形，并在检索器共享同一活跃存储与参与者信息后与原参照排序器做预设 0.02 边际的等价检验。

## 论文做了什么

主要贡献是把 Personal Fact Memory 作为参照层直接测量修订失败，并用预设 0.02 边际做等价检验。

## 证据与发现

作者报告：只服务活跃值时观察到的陈旧暴露消失；不做更新消解时 70.3% 的提示会暴露被取代的值。检索器共享活跃存储后，参与者感知的 BM25 在预设边际内与原参照排序器等价。作者指出更难的问题是“把修订分配给正确的槽位”：漏合并会让陈旧值继续活跃，误合并则会静默移除当前值。

## 可复用模式

记忆评测应直接测量生成前的失败类型，而不是只看答案正确率；同时说明哪些失败来自检索、哪些来自槽位分配。

## 局限性与开放问题

受控修订基准与个人事实场景；结论中“等价”是在预设边际内的等价，不等于完全一致。

## 与本索引的关系

与 Temporal Memory Admission、Retrieval Admissibility 同属“生成前”的诊断层，并补充了槽位分配这一独立失败面。
