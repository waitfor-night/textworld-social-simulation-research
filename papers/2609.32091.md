## 一句话要点

把记忆当作中间件而不是每个 agent 自带的功能，才能替换、共享、隔离并独立推理。

## 研究对象

- **世界或环境：** cross-session agent runtime
- **智能体：** agents with swappable memory layer
- **观察与动作：** 跨会话的持久知识与 agent 运行时的交互。
- **目标与交互协议：** 提出六个系统层面的挑战：双向可插拔、宿主原生介入、多租户隔离、写路径一致性、带来源的联邦共享、生命周期治理，并给出参考实现 ALTK-Evolve。

## 论文做了什么

论证 agent 记忆应成为一等、可插拔的基础设施层，如同数据访问、消息与持久化。

## 证据与发现

本文为立场与系统设计论文，摘要未报告对照实验结果；不应把其框架视为已验证的性能改进。

## 可复用模式

与当前“先不引入独立记忆模块”的取舍一致：只有当多个角色或系统需要共享/隔离记忆时，中间件层才值得存在。

## 局限性与开放问题
