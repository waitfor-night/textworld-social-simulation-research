# Semantic Overlays: Mitigating Prompt Injection with Annotations Beyond Tokens and Steering Vectors

- **作者：** Joshua Penman
- **日期 / 版本：** 2026-08-24 首次提交；2026-09-03 v3

- **主领域：** SAFE — 提示注入与权限安全
- **相关性：** `core`
- **标签：** `prompt-injection;security;representation-steering;tool-use;reproducibility;benchmark;open-source`

## 一句话要点

Semantic Overlays 在冻结模型残差流中加入标注跨度身份的非文本通道，试图让“不可执行的外部内容”与可执行指令在权限层面分离。

## 研究对象

- **世界或环境：** 带用户输入、工具输出和指令跨度标注的模型预填充/推理环境，以及多个提示注入基准。
- **智能体：** 使用冻结 Qwen3.5-9B 的工具型代理和攻击提示；另在 Llama-3.1-8B-Instruct 上做部分复制。
- **观察与动作：** 模型读取带 overlay 的文本并生成回答或工具相关行为；防御器对指定跨度施加训练适配器。
- **目标与交互协议：** 保持底层内容可读，同时让标记为 non-executable 的不可信跨度不触发额外指令；在 SEP、TensorTrust、AlpacaFarm、PIArena 等基准上测攻击和效用。

## 论文做了什么

论文提出可训练、可组合且选择性应用的 Semantic Overlay 适配器，将跨度身份作为超越 token 的表示通道。作者还审计并修正部分基准评分/过滤问题，报告 Qwen 主实验、三种随机种子和 Llama 复制结果。

## 证据与发现

作者报告 SEP separation 从 24.3% 提升到 99.0%，TensorTrust 攻击成功率从 34.8% 降至 6.2%，AlpacaFarm 从 99.0% 降至 0%，并保持超过 95% 的字符相似度；这些数字使用作者修订后的评分规则。论文也说明大部分结果来自单一模型尺度，且外部红队并未在第二模型上完整复现。

## 可复用模式

- 把来源、信任级别和可执行权限作为结构化输入，而非只靠文字约定；
- 同时报攻击成功、任务效用和内容可读性；
- 对注入基准的过滤、grader 缺陷和清洁控制单独做审计。

## 局限性与开放问题

主要结果来自一个 Qwen 模型和冻结推理设置，overlay 训练数据、层位和部署栈会影响效果。非文本通道本身需要受信任的 serving 实现，不能自动覆盖未知攻击面或被攻破的控制平面。
