## 一句话要点

企业工作流里，动作要合规、工具反馈会隐藏副作用、长程任务需要跨记录持续跟踪状态——因此需要把“已验证的隐藏规则 + 有证据的动态状态”作为一份世界账本显式维护。

## 研究对象

- **世界或环境：** enterprise workflows with partially observable tool feedback
- **智能体：** E-Ledger multi-agent harness with code approval layer
- **观察与动作：** 受策略检查的候选动作、工具反馈中被隐藏的副作用，以及跨多条记录的状态。
- **目标与交互协议：** E-Ledger 在执行前用代码审批层检查每个动作；维护包含已验证隐藏规则与有证据动态状态的世界账本；WorldAbduct 从状态一致性、世界—观察差距、策略门控正确性与目标判定四个视角诊断轨迹，归纳潜在规则并据此演化 harness。

## 论文做了什么

把安全执行与持久状态跟踪放在同一个 harness 里，并把“未知的隐藏规则”作为需要被推断和验证的对象，而不是假定已知。

## 证据与发现

作者指出部分可观察性使工具反馈掩盖副作用、长程任务要求跨记录状态跟踪。摘要未给出具体评测数值。

## 可复用模式

世界账本 = 已验证规则 + 有证据的状态，正好对应本项目 Authority 与 Observation 的分离；隐藏规则需要被推断、验证后写入，而不能直接采信。

## 局限性与开放问题

面向企业工作流的合规场景；机制描述为主，摘要缺少对照实验与代码链接。
