## 一句话要点

把对话存成不可变 episode，再用版本化 schema 组织当前与历史状态，避免反复调用大模型重写既有交互。

## 研究对象

- **世界或环境：** long conversational agent memory
- **智能体：** memory controller over immutable episodes
- **观察与动作：** episode 与版本化 schema 之间的状态转移（reinforce / supersede / split / create）。
- **目标与交互协议：** 用最小能量状态转移把新 episode 归入 schema，保留当前与历史两种状态。

## 证据与发现

作者指出理想记忆系统需同时保留当前与历史状态、区分陈旧与活跃知识、按查询检索合适证据，并避免重复 LLM 改写；摘要未报告具体数值。

## 可复用模式

“当前值 + 历史值 + 变更方式”是一个可复用的最小记忆形态，与 MoM 的类型化操作相呼应。
