## 一句话要点

构建记忆相对“直接从原始历史检索”的净价值往往为负：作者把净价值拆成记忆收益与**记忆税**。

## 研究对象

- **世界或环境：** multiple memory benchmarks and model backbones
- **智能体：** dedicated memory systems versus naive RAG
- **观察与动作：** 相对 RAG 基准的收益与损失，以及记忆过程如何改变模型的可用信息。
- **目标与交互协议：** 跨多个基准与模型主干做大规模评测，以 naive RAG 为参照分解净价值。

## 论文做了什么

提出“记忆税”概念，把记忆系统的净价值分解为收益与损失。

## 证据与发现

作者报告许多专用记忆系统在多基准上不如 naive RAG，表明净价值为负（具体数值需核对正文）。

## 可复用模式

与本项目当前的“只用最近事件 + 关键词重叠”直接相关：在没有测出稳定净收益前，引入记忆系统是负期望。

## 局限性与开放问题

以 RAG 为参照；税的定义依赖该参照的实现。
