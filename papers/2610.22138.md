## 一句话要点

群体讨论被认为能互相纠错，但对抗性少数会让良性 agent **私下采纳**错误答案：三个对抗者把良性 agent 最终持错误答案的比例从 0.6% 提到 60.5%，而公开表态只有 19.7%。

## 研究对象

- **世界或环境：** ten-agent factual discussions with one or three adversaries
- **智能体：** private answer probes hidden from peers plus public stance labels
- **观察与动作：** 每轮后通过一次对同伴不可见的独立调用探测的私人答案，以及单独标注的公开立场。
- **目标与交互协议：** 十 agent 事实讨论：一个或三个对抗 agent 反复主张一个看似合理的错误答案；六个模型、三个事实问答数据集。

## 论文做了什么

提出用“私有答案探针 + 公开立场标注”分离私下改变与公开顺从的测量方法，并在对抗性少数设定下量化隐藏的信念崩塌。

## 证据与发现

作者报告无攻击者时良性 agent 最终持错误答案仅 0.6%，一个攻击者升到 44.8%、三个升到 60.5%；三个攻击者时良性 agent 在 51.6% 的暴露轮次中私下持错误答案，但只有 19.7% 公开背书；保留正确答案的 agent 往往也无法为之辩护，一旦被采纳，错误答案会在良性 agent 之间传播，而基线知识并不能预测鲁棒性。

## 可复用模式

“私下信念”与“公开立场”必须分开测量，否则会严重低估社会影响；这对本项目多角色社会中的谣言传播是直接的方法论要求。

## 局限性与开放问题

事实问答场景与固定十人结构；对抗者的主张被设计为“看似合理的错误答案”。
