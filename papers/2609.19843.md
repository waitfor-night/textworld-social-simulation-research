## 一句话要点

论文用双过程理论在 3,600 个 GUI agent 上做随机在线购物实验，发现推理配置并非提高稳健性，而是改变了 nudged 的生效路径。

## 研究对象

- **世界或环境：** 为人类设计的在线购物界面。
- **智能体：** 三家供应商、六种前沿模型的 GUI agents。
- **观察与动作：** 默认选项式（Type 1）与社会影响式（Type 2）nudge，以及最终购买决策。
- **目标与交互协议：** 21,600 次模拟的随机实验，比较不同 reasoning 配置。

## 论文做了什么

分别测量两类 nudge 的易感性，并分析 reasoning configuration 与模型规模的调节作用。

## 证据与发现

作者报告 agent 对两类 nudge 均易感；开启推理降低了默认 nudge 的易感性，却提高了社会影响型 nudge 的易感性，因此更多推理只是改道而非免疫。

## 可复用模式

界面选择架构应被视为 agent 治理变量，评测需分别报告不同 nudge 类型的方向性效应。

## 局限性与开放问题

购物场景与构造 nudge 限制外推；摘要未确认代码或数据开放。
