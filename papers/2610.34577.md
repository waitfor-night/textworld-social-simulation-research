## 一句话要点

验证是测试时扩展的一个轴：需要研究何时介入、由谁检查、以及检查如何转化为修订；框架横跨初始指令、回合中提醒、完成闸门与独立审查四层。

## 研究对象

- **世界或环境：** agent lifecycle from initial instructions to independent review
- **智能体：** framework comparing four verification layers
- **观察与动作：** 四层验证介入下 agent 的输出质量与成本。
- **目标与交互协议：** 把验证作为测试时扩展轴做系统研究，比较四层的效果。

## 论文做了什么

提出以四层生命周期为骨架的验证组织框架，并给出 harness 层面的设计指引。

## 证据与发现

作者指出关于 harness 应如何组织验证工作缺乏指引；摘要未给出量化结果。

## 可复用模式

与 Probe-and-Resume 的“只在声称完成时验证”、HICO-Bench 的产物核验合起来构成本项目验证层的设计空间。

## 局限性与开放问题

面向通用 agent harness；四层的成本未在摘要中量化。

## 与本索引的关系

与 Probe-and-Resume、AgentEval、Rethinking Verification 同属验证时机与方式。
