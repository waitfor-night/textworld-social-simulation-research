## 一句话要点

扩展协作 agent 环境需要同时保持任务目标、可执行资源、用户行为与成功标准之间的一致性；用“构建—执行—修正”循环加上有状态的用户模拟器可以大规模合成这样的环境。

## 研究对象

- **世界或环境：** 64.9K synthesized environments across 14 application scenarios
- **智能体：** build-execute-revise loop plus stateful user simulator editing the workspace
- **观察与动作：** 跨工具与文件的依赖、变化中的用户需求，以及用户对共享工作区的直接编辑。
- **目标与交互协议：** Cowork-Gym 用执行证据与评审反馈验证并修复生成的环境；有状态的用户模拟器通过对话与直接编辑共享工作区来回应 agent 的动作；合成 64.9K 个环境、覆盖 14 个应用场景，并用其以监督微调、强化学习与在线策略蒸馏后训练 9B、27B 与 35B-A3B 的 Qwen 模型。

## 论文做了什么

主要贡献是 Cowork-Gym：以构建—执行—修正循环合成 64.9K 个协作环境，并配有状态用户模拟器直接编辑共享工作区。

## 证据与发现

作者报告在六个 agent 基准上平均，三个规模分别比对应基线提升 8.7、6.4 与 4.1 个点；27B 模型综合排名第二，并在 PawBench 与 ClawEval 上取得最高平均分，超过参数量大于 100B 的模型。

## 可复用模式

“用户直接编辑共享工作区”是本项目多角色环境的天然形态：环境变化既可以来自角色的动作请求，也可以来自其他角色或用户对同一状态的修改。

## 局限性与开放问题

环境为合成并以软件协作为主；用户模拟器的行为分布决定训练与评测的有效性。
