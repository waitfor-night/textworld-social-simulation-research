## 一句话要点

文本写下的约束无法强制遵守；要让互不信任的 agent 之间形成可依赖的约定，需要让 agent 在操作执行前提交机器可检验的证明，证明它在自身模型的每种允许情形下都保持约定约束。

## 研究对象

- **世界或环境：** requested operations under agreed constraints
- **智能体：** PC2 plus Airlock execution system
- **观察与动作：** 请求的操作、约定需保持的条件，以及 agent 提交的证明。
- **目标与交互协议：** PC2 要求 agent 提供机器可检验的证明；执行系统 Airlock 检查证明并控制对操作的访问；各方只规定需保持的条件，agent 自行提供论证并可自由调整策略；给出“约束在执行期间每一时刻都成立（即便面对对抗性 agent）”的证明，并界定何时这蕴含现实世界的安全。

## 论文做了什么

提出 Proof-Carrying Contracts 与 Airlock 执行系统：以可检验证明替代“设计权限策略并证明其安全”。

## 证据与发现

为形式化框架，摘要给出安全性证明与“可复用能力模块”设计；未给出大规模实证数值。

## 可复用模式

“证明携带”是授权与结算之间的第三条路：不必预先枚举允许动作，只要求每次操作自带保持约束的论证——与本项目 World 结算前校验 ActionRequest 天然契合。

## 局限性与开放问题

需要为每个操作提供可判定的约束模型；现实世界安全的蕴含条件受限。
