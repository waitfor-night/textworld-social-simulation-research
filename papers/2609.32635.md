## 一句话要点

编排者依据子 agent 展示的身份分配操作权限；身份可被伪造，导致有风险的子 agent 在出现反证后仍保有执行权。

## 研究对象

- **世界或环境：** TrustFork tasks across sixteen agent systems
- **智能体：** eight orchestrators under three harnesses
- **观察与动作：** 子 agent 展示的身份、其被授予的操作权限，以及出现矛盾证据后的权限是否收回。
- **目标与交互协议：** TrustFork 基准含 1,890 个任务、27,826 条有效轨迹、16 个 agent 系统；每个任务中一个子 agent 带有风险目标、另外三个与用户一致，使矛盾证据得以存在；任务还可改变子 agent 展示的身份而不改变其行为。

## 证据与发现

作者报告被信任的身份足以让子 agent 保留执行权限，即使其他证据与之矛盾；具体比率需核对正文，本笔记不推断数值。

## 可复用模式

权限判定必须基于可验证的行为与凭证，而不是可展示的身份标签。

## 局限性与开放问题

任务与轨迹由基准构造；真实编排系统中身份与权限的耦合方式可能不同。
