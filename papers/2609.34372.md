## 一句话要点

人格不应只写在提示里：记忆的优先级、检索与情感评估本身也应由人格参数决定，否则无法验证行为是否与人格一致。

## 研究对象

- **世界或环境：** role-playing agents with dual-pathway memory
- **智能体：** PersMem personality-integrated memory
- **观察与动作：** 用户输入的情感评估、既有记忆的保留、被动情感驱动的检索与后续处理。
- **目标与交互协议：** 把人格映射为记忆处理各步骤的操作参数，形成四步人格相关流水线。

## 证据与发现

作者指出人格与记忆处理分离会导致行为难以与既定人格对应，并提出 PersMem 使记忆处理始终依赖人格。摘要未给出具体评测数值。

## 可复用模式

若要让角色差异影响轨迹，检索与保留策略本身是可介入的差异来源，而不只是语言风格。
