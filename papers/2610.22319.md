# A team of Gemini 4 Argon agents beats Minecraft

- **标识符：** arXiv:2610.22319
- **作者：** Maxence Faldor, Satinder Singh, Roberta Raileanu
- **日期 / 版本：** 2026-10-15 提交，版本 1（2026-10-19 收录）
- **规范链接：** https://arxiv.org/abs/2610.22319
- **代码 / 数据：** 未确认公开仓库
- **主领域：** SIM — 社会与叙事模拟
- **相关性：** `core`
- **标签：** `long-horizon;multi-agent;shared-memory;minecraft;autonomous-completion`
- **观察日期：** 2026-10-19
- **置信度：** `high`

## 一句话要点

四个 agent 在沙盒 Minecraft 中仅凭一句话目标（击败末影龙）、游戏内聊天与共享记忆完成通关；没有人分配角色或写游戏逻辑，所有程序由 agent 自己编写与调试。

## 研究对象

- **世界或环境：** sandboxed Minecraft survival world on Easy difficulty
- **智能体：** four Gemini 4 Argon agents via Mineflayer with chat and shared memory
- **观察与动作：** 每个 agent 控制的玩家、游戏内聊天、共享记忆，以及自行编写的程序。
- **目标与交互协议：** Mineflayer 控制玩家；随机生成世界、Easy 难度；研究者只能通过仪表盘观看或暂停，没有介入的理由。

## 论文做了什么

报告一次端到端自主通关的完整运行：团队共编写 2,783 个程序，用 27 小时 14 分钟击败末影龙，途中死亡 605 次。

## 证据与发现

作者称这是首个仅用标准 Mineflayer 库、无预先勘察种子或人写游戏专用工具的 AI agent 端到端通关；获胜要求 agent 在数千个相互依赖的步骤上维持一致计划超过一天。

## 可复用模式

共享记忆 + 聊天 + 无预设角色，是“多角色社会”最简配置的一次长程验证；也说明一致计划可以跨数千步维持，而不需要显式的计划模块。

## 局限性与开放问题

单一游戏与固定难度；共享记忆的内容与冲突处理细节未在摘要中说明；27 小时运行的成本未评估。

## 与本索引的关系

与 Voyager 的自主探索、MultiWorldBench 的共享世界一致性形成“同一世界的多 agent 长程运行”这一线上的实证点。
