## 一句话要点

长任务 agent 会重复已经做过的事——重新发出之前的工具调用并得到完全相同的观察，一步没有新增信息；这种循环在历史被压缩到上下文窗口内之后显著增多。

## 研究对象

- **世界或环境：** long-horizon agent rollouts from Qwen Llama and Gemini agents
- **智能体：** DeLoop contrastive preference pairs from looping and later non-looping actions
- **观察与动作：** agent 自己的 rollout 中的循环动作，以及同一 rollout 中其后第一个非循环动作。
- **目标与交互协议：** 把循环动作作为负例、其后第一个非循环动作作为正例，用直接偏好优化学习，不需要任务奖励、标准答案或 LLM 裁判。

## 论文做了什么

主要贡献是 DeLoop：以循环动作与后续非循环动作构造偏好对的自监督修复方法。

## 证据与发现

作者报告循环在 Qwen、Llama 与 Gemini agent 中自然出现；在压缩下的 CodeGym 上，DeLoop 把含循环的 Qwen3-8B 任务比例从 57.3% 降到 6.1%，每任务步数约为三分之一而任务成功率相近；在 Qwen3-32B 上减少循环与步数的同时把成功率从 37.7% 提到 44.8%。

## 可复用模式

这是对本项目“记忆压缩”决策的直接警告：压缩历史会诱发循环；若将来引入压缩，必须同时监控重复动作率，并可用同类自监督信号修复。

## 局限性与开放问题

以重复工具调用且观察相同为循环定义；不同工具语义下的等价动作不算循环。
