## 一句话要点

让模型“凭直觉立刻回应”而不是分析式推演，对个体反应的预测最准，并把个体差异的压缩从人类水平的七倍降到三倍。

## 研究对象

- **世界或环境：** 8 名塞尔维亚参与者（问卷、深度访谈、自述），对 68 条社交媒体帖子的真实反应。
- **智能体：** 四个语言模型在五种提示条件下（profile 内容与指令风格变化）。
- **观察与动作：** 预测被试对帖子的态度反应；另测 agent 与自身被给定 profile 的一致性。

## 证据与发现

作者报告态度类内容远优于人口统计背景；agent 与被陈述 profile 的一致度高于参与者与自身问卷回答的一致度，且一致性一旦有 profile 信息就与保真度无关；直觉式指令保真最高，并在问卷未涉及的话题上同样最好，超过群体基线。

## 可复用模式

profile 里写态度与偏好，比写人口统计更有效；同时必须把“与 profile 自洽”和“与真人一致”作为两个不同指标分别报告。

## 局限性与开放问题

仅 8 名参与者且全部来自塞尔维亚，作者明确说明不能推断总体参数，模型间差异在该样本量下也达不到常规显著性；结论基于单项研究的 item 级比较。
