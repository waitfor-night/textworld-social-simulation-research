# Agent Name Collision Attacks in Multi-Agent Systems

- **标识符：** arXiv:2609.27624
- **作者：** Adithyan Arun Kumar
- **日期 / 版本：** 2026-09-23，版本 1

- **主领域：** SAFE — 多角色身份路由
- **相关性：** `adjacent`
- **标签：** `identity;routing;name-collision;multi-agent-security;dispatch;interoperability`

## 一句话要点

把远程声明的可读名称当成本地路由标识，会让请求被派发给错误的对端；名称不是身份。

## 研究对象

- **世界或环境：** A2A 风格的 agent 主机：注册、路由与分派链路；七个固定的开源修订版。
- **智能体：** 客户端式集成与中介式（brokered）实现中的多个对端。
- **观察与动作：** Agent Card 名称、注册、请求分派与访问控制状态。

## 证据与发现

作者报告六个客户端式集成会选择攻击者控制的对端或回环端点来响应发给受信对端的请求；第七个中介实现把两个对端折叠到同一名称派生路由，结果是拦截或拒绝取决于队列与访问控制状态。合成的凭证与工具测试未发现 A 的凭证直接转移，也未发现 A 拥有的工具被直接转移。

## 可复用模式

角色身份需要独立于显示名称的稳定标识；路由与授权不得依赖人类可读名称。

## 局限性与开放问题

结果集中于被测试的七个修订版与 A2A 风格接口；其他协议栈是否同样脆弱未知。

## 与本索引的关系
