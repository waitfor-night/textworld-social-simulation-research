## 一句话要点

持久记忆有两个不同的治理决定：哪些被召回内容可以进入工作上下文（admission），以及被接纳的信息如何表达（presentation）。

## 研究对象

- **世界或环境：** personalized agent memory across domains
- **智能体：** four backbone models with deterministic eligibility policies
- **观察与动作：** 召回的记忆条目、其中的类型化单元，以及判定属性到资格决定的确定性策略。
- **目标与交互协议：** 实现两种免训练推理时设计：factor-compiled admission 评估整条记忆条目，permission-semantic admission 把条目分解为类型化单元；两者都通过确定性策略把裁决属性翻译成资格决定。在四 backbone 开发套件与四个各 300 样本任务的外部基准上评测。

## 证据与发现

作者报告相对逐字注入，FC 与 PS 把外部基准上的合并判定失败率降低 6.7 与 8.8 个百分点（p = 2.7e-7 与 4.1e-12），开发集跨域泄漏最多下降 29.5 个百分点。

## 可复用模式

记忆治理要分两层实现：先决定资格（可用确定性策略），再决定表达方式；两者混在一起会同时产生谄媚与跨域泄漏。

## 局限性与开放问题

评测以判定器评估的失败率为主；资格判定的属性来源与维护成本未在摘要中说明。
