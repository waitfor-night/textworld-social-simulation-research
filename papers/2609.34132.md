## 一句话要点

持久记忆攻击通常只测是否成功，但成功的攻击在下游后果上差异巨大；应把严重程度当作独立目标。

## 研究对象

- **世界或环境：** persistent agent memory interfaces
- **智能体：** LLM agents with offline paired-loss feedback
- **观察与动作：** 持久记忆接口、稀疏有据的语义编辑，以及相对干净记忆的成对下游损失增加。
- **目标与交互协议：** 形式化 counterfactual memory regret (CMR)，提出 MemHarm：预先声明有限的稀疏编辑类，通过正常记忆接口评估候选并依据离线成对损失反馈，在该类内认证选出的编辑。

## 证据与发现

作者报告相较以攻击成功为目标的优化，CMR 引导的选择在下游损失上明显更大，同时保持较低的成功率要求。摘要未给出具体数值。

## 可复用模式

记忆安全评测应报告后果严重程度，而不只是攻击是否生效。

## 局限性与开放问题

依赖成对离线损失反馈与可枚举的编辑类；开放场景中的后果难以度量。
