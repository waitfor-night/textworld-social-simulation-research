## 一句话要点

让 agent 在固定预算内复现论文的指定结果，并按作者发布物的完整程度分层；越缺代码越差。

## 研究对象

- **世界或环境：** 100 篇 NeurIPS 2025 论文，按 Run / Retrain / Reimplement 三档难度分层，每篇预先固定要复现的结果、成功判据与 GPU 小时预算。
- **智能体：** 四个 agent，每篇运行一次。
- **观察与动作：** 使用论文与作者发布的代码、数据、权重进行复现；由独立模型依据日志和产物评分。

## 证据与发现

作者报告最强 agent 在 Run 档复现 41%、Retrain 档 27%、Reimplement 档仅 15%；失败尝试平均只用掉 29% 预算，多数在预算仍有剩余时停止；最常见错误是“写出方法却不与论文数字核对”，出现在 400 次运行中的 63 次。

## 可复用模式

把“声称完成”与“证据核对”分开评测；报告预算使用率和停止原因，而不只报成功率。

## 局限性与开放问题

评测对象是 ML 论文复现，不是角色或社会模拟；评分仍依赖模型裁判。

## 与本索引的关系

与 Agent Audits Whom、MIRAGE 一致地强调证据来源与可核验性；也提示“过早停止”是长程任务的独立失败模式。
