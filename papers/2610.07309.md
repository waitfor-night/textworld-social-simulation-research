## 一句话要点

检索到的信息可能相关却不可用：它属于另一个主体、违反策略，或处于不兼容的生命周期状态——而召回率和最终答案正确率都看不出来。

## 研究对象

- **世界或环境：** frozen rankings from two public long-term memory sets
- **智能体：** long-term memory agents
- **观察与动作：** 记忆—查询对的状态（admissible / inadmissible / unresolved），以及记忆 ID 是否进入 prompt。
- **目标与交互协议：** 在匹配必要证据召回的前提下比较不同路线，并对 unresolved 情形给出界；同时追踪 memory ID 到 prompt 暴露、再把暴露关联到目标级披露。

## 论文做了什么

主要贡献是把 memory ID 的 prompt 暴露与目标级披露串起来的追踪设计，并对 unresolved 情形给出界。

## 证据与发现

作者指出“看起来安全”可能是因为缺失必要证据，而正确答案也可能来自不合规的 prompt 暴露；各阶段在互不合并的样本上评测，具体数值需核对正文。

## 可复用模式

记忆评测不能只看答对与否，需分别检查“取到了什么”“有没有进入上下文”“是否该给这个主体看”。

## 局限性与开放问题

摘要未给出完整数值；admissibility 的判定规则来源与可维护性未说明。

## 与本索引的关系

把 Epistemic Admission 的“能否写入”扩展到“能否被这个主体看到”，并把 prompt 暴露作为独立观测对象。
