## 一句话要点

WorldMind 提出一条解耦循环：从紧凑的世界状态理解出发，到 NPC 决策、时序控制，再到生成的结果。

## 研究对象

- **世界或环境：** 与内部游戏状态信息配对的对局视频。
- **智能体：** 游戏世界中的非玩家角色（NPC）。
- **观察与动作：** 模型提取紧凑状态，选择动作，在时间上对齐条件，并生成视觉结果。
- **目标与交互协议：** 闭环的状态感知 NPC 行为；摘要描述了一个 BOSS-140K 对局视频/内部状态数据集。

## 论文做了什么

该论文将功能分为四部分：Understanding、Decision、Control 与 Generation。这种分离旨在让持久状态与动作选择保持显式，同时让最终输出层专注于时序与视觉呈现。

## 证据与发现

论文报告了状态接地与行为偏好上的评估，摘要中提到约 70% 的两两偏好胜率。该声明仅记录于摘要层面，在将其作为基准结果使用前，应核对全文与已发布的项目材料。

## 可复用模式

- 将权威状态与叙事或视觉渲染分离。
- 将时序控制作为独立组件处理，而非隐藏在自由形式的生成中。
- 使用闭环，使结果能够更新下一状态与动作决策。

## 局限性与开放问题

这是视觉游戏世界模型，而非文本原生世界模型。摘要未说明该方法对部分可观察性、长程社会记忆、反事实分支或文本动作接口的处理效果。

## 与本索引的关系

这是所提议的 `world state → projection → agent action → event commit → rendering` 流水线的一个相邻系统参考。最值得借鉴的是状态、决策、控制与输出之间的显式分离。
