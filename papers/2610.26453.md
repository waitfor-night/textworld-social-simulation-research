## 一句话要点

在生成、交互与记忆预算都很紧的条件下，成熟的长时记忆方法可能几乎不优于简单检索甚至无记忆；关键不是“检索到相关经验”，而是判断哪些经验真正值得保留与复用。

## 研究对象

- **世界或环境：** three LifelongAgentBench environments;local and API deployments
- **智能体：** TokenWorth learning query-dependent memory worth from execution feedback
- **观察与动作：** 查询相关的记忆价值，以及保留/复用决策对稀缺上下文的占用。
- **目标与交互协议：** TokenWorth 从稀疏执行反馈中在线学习查询相关的记忆价值，并把同一价值判断一致地用于检索与有界记忆管理；在三个 LifelongAgentBench 环境、本地与 API 部署上评测。

## 论文做了什么

提出 TokenWorth：以在线学到的“记忆价值”同时驱动检索与容量管理的轻量框架。

## 证据与发现

作者报告在评测方法中取得最高任务成功率，同时输出 token 最少。结论是资源受限下的持续适应取决于“学到什么值得记”，而不是“记得更多”。

## 可复用模式

这对本项目是直接的预算论证：记忆不是越多越好，价值判断应与容量管理用同一把尺子。

## 局限性与开放问题

三个基准环境；价值学习依赖稀疏执行反馈的可得性。
