## 一句话要点

agent 出错后可能自行恢复，因此外部干预的时机需要判断：应当优先干预那些不太可能自恢复的错误，而允许可能自恢复的情况继续执行。

## 研究对象

- **世界或环境：** 1259 traces and 1403 error events in computer-use and web tasks
- **智能体：** ReInBench and ReCoF recovery prediction
- **观察与动作：** 1,259 条 agent 轨迹与 1,403 个错误事件；自恢复的频率、速度及其与后续执行和任务完成的关系。
- **目标与交互协议：** 构建 ReInBench（覆盖计算机使用与 Web 任务）；检验自恢复何时可预测；提出 ReCoF 预测某错误是否会自恢复以决定是否干预。

## 论文做了什么

构建 ReInBench 并量化自恢复，提出预测自恢复的 ReCoF。

## 证据与发现

作者报告 725 个错误事件自恢复，常在数步内完成，且自恢复表现因执行 LLM 而异；自恢复还能帮助 agent 从后续同类型错误中恢复并支持整体任务完成；ReCoF 在 ReInBench 上相对最强基线的 Macro-F1 平均提升 9.02%。

## 可复用模式

“错误可能自愈”对监控设计是重要约束：过早介入可能反而打断恢复；本项目的角色应被允许在 World 中重试。

## 局限性与开放问题

两个任务域与固定模型集；自恢复的判定依赖具体轨迹标注。
