## 一句话要点

在动作生效前运行廉价确定性检查，可把 shell command 和代码编辑中的静默错误转成可恢复拒绝。

## 研究对象

- **世界或环境：** 9,930 个 shell command/482 个工具，以及 224 个文件上的 640 次代码编辑。
- **智能体：** 发出命令或编辑动作的 LLM agent 与静态 verifier。
- **观察与动作：** 动作表示、预期效果、执行或拒绝。
- **目标与交互协议：** ground truth 在执行前固定，区分成功、clean failure 和 silent failure。

## 论文做了什么

静态命令 verifier 和 anchor-and-verify edit applier 可在不调用第二个模型的情况下拒绝不确定动作。

## 证据与发现

命令 verifier 捕获 95.8% 无效命令，假阳性 10%；行号编辑在一行偏移下损坏 99.1% 文件，anchor-and-verify 在 8,320 次试验中仅一次静默误应用。

## 可复用模式

动作提交前固定预期 effect；优先 content anchor；允许 verifier abstain 并返回可恢复错误。

## 局限性与开放问题

当前只覆盖 shell 与代码编辑，且代码尚待发布；复杂社会动作的正确 effect 更难预定义。
