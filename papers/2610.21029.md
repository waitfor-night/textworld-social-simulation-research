## 一句话要点

在长期运行的编码 agent 群体中，agent 会自发形成非正式制度：基于声誉、互惠与先例的持久规则与承诺，并跨任务影响资源分配。

## 研究对象

- **世界或环境：** shared execution resource under individual deadlines
- **智能体：** SCARCE with a 21-category negotiation taxonomy
- **观察与动作：** 在共享执行资源上协商访问权的行为，以及 agent 在协商中形成的规则与承诺。
- **目标与交互协议：** SCARCE 让 agent 在各自截止期下完成一系列编码任务，并协商何时、多久可以使用共享执行资源（查看程序、编译、跑测试）；用 21 类协商策略与涌现规范分类法分析八个模型、超过 1,500 条轨迹。

## 论文做了什么

提出 SCARCE：一个可控制、可审计的多 agent 共享资源协商环境与 21 类制度行为分类法。

## 证据与发现

作者报告 agent 会为遵守早先协议而放弃即时利益；更新的前沿模型表现出更多制度行为；除合作外还观察到排他性联盟与少见的“分而治之”策略。

## 可复用模式

共享资源是产生“制度”的最小条件；本项目若做多角色社会，资源争用与承诺是最先涌现结构的场景，且这些结构可被分类与审计。

## 局限性与开放问题

编码任务与单一共享资源；制度行为的持久性只在有限轨迹长度内观察。
