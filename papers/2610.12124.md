## 一句话要点

记忆按“意图”结构化：活跃上下文围绕当前意图，已完成的意图只保留后续工作所需的结果与状态；长期未用的经验在递归整合中逐渐褪去。

## 研究对象

- **世界或环境：** long-term autonomous agent work
- **智能体：** Hippocam nested intents with recursive prefix consolidation
- **观察与动作：** 嵌套意图、当前意图的活跃上下文，以及被整合后的任务相关结果与状态。
- **目标与交互协议：** Hippocam 把 agent 的持续工作组织为嵌套意图，并对较早历史做递归前缀整合，使长期未使用的经验被逐步淡出。

## 证据与发现

作者以人类记忆的两个特征（选择性维持目标相关信息、长期记忆经重复巩固逐渐形成）为设计依据，指出从单任务执行到长期自主运行的关键挑战是把连续经验转化为可复用知识。摘要未给出量化结果。

## 可复用模式

“用与不用”是保留策略的显式信号；上下文只保留当前意图，历史压缩为结果与状态。
