## 一句话要点

RIR 将恢复建模为 rollback boundary 控制：回滚被污染的世界状态，同时把废弃轨迹中的可复用反思带到新分支。

## 研究对象

- **世界或环境：** ALFWorld、ScienceWorld 和 GAIA，分别覆盖具身交互、科学实验和开放域工具使用。
- **智能体：** 以 Qwen3-14B 和 DeepSeek-V3 为 backbone 的行动代理。
- **观察与动作：** 错误动作、后续状态、rollback depth 和保留 reflection memory。
- **目标与交互协议：** 在有限交互预算下联合决定何时干预、回到哪里、哪些知识跨分支保留；对照 ReAct、Self-Refine、Reflexion、LATS 与 GA-Rollback。

## 论文做了什么

将恢复拆为三个子问题：hybrid adaptive review 决定何时干预，coarse-to-fine restore localization 决定回到哪里，rollback-consistent reflection memory 决定保留什么。统一操作符同时控制 state restoration 与 retained memory，并在理论上证明常见 correction/rollback 机制是其受限特例，由此给出最优值单调性。

## 证据与发现

v2 作者报告跨两个 backbone、三个 benchmark 平均成功率提升最多 6.57 个百分点；ScienceWorld 另报 normalized dense reward，GAIA 使用 LLM-as-a-Judge 判断语义等价。v3 重写摘要，把贡献更明确表述为 rollback depth 与 retained memory 的统一操作符，并强调 structured reflection 与 selective rollback；摘要不再列出 6.57pp 数值，但旧版实验记录仍保留于本笔记。

## 可复用模式

世界快照和记忆 lineage 分离；回滚必须生成新 branch ID，并标记跨分支带入的反思。

## 局限性与开放问题

GAIA 的评估依赖 LLM-as-a-Judge，其与可验证成功的一致性未被独立检查；reflection 可能从失败分支携带错误归因；论文未提供公开代码，且最优值单调性以操作符的受限特例关系为前提。
