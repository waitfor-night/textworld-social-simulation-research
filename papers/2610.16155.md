## 一句话要点

用行为大体配合的标准用户模拟器评测交互式 agent，会高估其鲁棒性；但为找出弱点而演化出的对抗用户又容易把任务本身弄失效。需要一种在保持任务完整性的前提下演化人格的方法。

## 研究对象

- **世界或环境：** four interactive-agent benchmarks;12 GPT-5.4 settings;28 agent-domain pairs
- **智能体：** TIPER reflection-guided behavioral mutations with task-integrity constraint
- **观察与动作：** 自动发现的、针对特定 agent 的用户策略；以及被保持有效且可解的任务本身。
- **目标与交互协议：** TIPER 通过反思引导的行为变异与在任务完整性约束下的任务级 Pareto 选择，演化持续存在的用户人格。

## 论文做了什么

主要贡献是 TIPER：在任务完整性约束下演化持续存在的用户人格，以暴露 agent 的鲁棒性弱点。

## 证据与发现

作者报告在四个交互式 agent 基准上，TIPER 在全部 12 个 GPT-5.4 设置中降低留出 avg@3（观测到 5.8 到 33.7 个百分点），并在覆盖七个 agent 的全部 28 个 agent—领域对中降低（中位数 22.9 个百分点）；另给出把发现的行为与反复出现的 agent 失败模式连接起来的行为—失败分类法。

## 可复用模式

评测角色鲁棒性时，用户本身就是环境的一部分；任务完整性约束（不能靠使任务失效来制造失败）是关键的方法论要求，与本项目“失败必须来自角色能力而非环境损坏”一致。

## 局限性与开放问题

评测对象为交互式 agent 基准，非社会模拟；演化出的用户策略是否对应真实用户的分布未验证。
