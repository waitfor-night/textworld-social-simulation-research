# DUMA-Bench: A Dual-Control Multi-Agent Benchmark for Evaluating LLM Agent Security

- **标识符：** arXiv:2609.24662
- **作者：** Ivan Aleksandrov, German Kochnev, Sabrina Sadiekh, Yaroslav Rogoza

- **相关性：** `core`
- **标签：** `dual-control;shared-state;security;adversarial-user;multi-agent;RAG-poisoning;benchmark`

## 一句话要点

DUMA-Bench 让用户和 agent 都能改变共享环境状态；加入这种双重控制后，作者报告攻击成功率由 26.9% 升至 41.1%。

## 研究对象

- **环境：** 从 τ²-bench 扩展的八个领域和八类漏洞，包括 RAG poisoning、跨 agent 操纵和不安全输出处理。
- **智能体：** 五个模型家族的 14 个模型，以及多种用户行为策略。
- **观察与动作：** 用户与 agent 对共享状态的交替观察和修改。
- **协议：** 比较静态/被动用户设定与 dual-control interaction 下的攻击成功。

## 论文做了什么

把安全性从单模型属性改为模型、用户和环境共同演化的交互属性，并提供对抗环境和用户行为分层评测。

## 证据与发现

作者报告 dual control 将总体攻击成功率从 26.9% 提高到 41.1%。这是 benchmark 内结果；摘要未提供各漏洞、模型和用户策略的完整分解，也未确认代码。

## 可复用模式

玩家必须是一等状态写入者；安全测试要覆盖用户在 agent 执行过程中修改环境、证据或目标，而不只是启动前给定恶意提示。

## 局限性与开放问题

扩展自既有工具任务，不能代表所有开放世界互动；漏洞覆盖和用户策略决定结果外推范围。
