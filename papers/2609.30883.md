## 一句话要点

基于同一模型的 agent 群体会因一句“别人可能会跟着走”的提示而集体挤向同一条路，并持续避开几乎空着的替代路线。

## 研究对象

- **世界或环境：** 双路拥堵博弈，100 轮；另有全人类组与混合组对照（共 480 名参与者）。
- **智能体：** 50 个 GPT agent 群体，以及两个其他模型家族的群体。
- **观察与动作：** 路线选择、平均通行时间、个体可改进幅度。

## 证据与发现

作者报告加入一句警告后，agent 群体挤向一条路并避开另一条，平均通行时间从 64 分钟升到 95 分钟，尽管任何拥挤路上的 agent 单独改道即可省 69 分钟；该模式持续 100 轮。另两个模型家族朝同方向偏移但未锁定单一道路；12 个全人类组（240 人）在数值报告或“提示+警告”下都保持接近均衡，混合组中失衡程度随 agent 比例上升。

## 可复用模式

共享模型 + 共享预测会产生相关性风险，而这是聚合指标看不到的；评测需设置全人类与混合对照以区分“模型行为”与“人类的反应”。

## 局限性与开放问题

拥堵博弈结构固定，结论不能直接外推到开放式社会互动；论文为预注册分析，模型家族样本有限。
