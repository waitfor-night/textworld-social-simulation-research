## 一句话要点

一条记忆可以既被正确检索、又与任务相关、还忠实于来源，却已经无权被用于行动——这是独立于存储与检索的时效准入问题。

## 研究对象

- **世界或环境：** Memora STALE Type II and ManBench-Return return episodes
- **智能体：** returning agents among four teammates
- **观察与动作：** 离开时的检查点、缺席期间发生的更新，以及返回者当前未完成的义务。
- **目标与交互协议：** 把重返协作视为资格判定：对账离场检查点与缺席期更新，处理显式与隐式失效，仅在覆盖返回角色未结义务时释放受限的 Return View。

## 论文做了什么

形式化 temporal memory admission，并给出免训练层 TRACE；在 Memora、STALE Type II 和派生的 ManBench-Return 上评测，每个场景都被改写成“一名 agent 离场、四名队友继续”的返回 episode。

## 证据与发现

作者报告在三种 actor 模型下 TRACE 均有效，且用于验证的核心是返回者是否可以依据旧记忆行动。摘要未给出具体数值。

## 可复用模式

角色与世界的时间推进必须区分“记得”和“现在还能据此行动”；返回场景是检验该区分的最小实验。

## 局限性与开放问题

评测基于三个改造过的记忆基准；作者未报告跨领域的长期运行结果。
