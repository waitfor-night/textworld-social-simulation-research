## 一句话要点

被当作 agent 护栏的类型化决策模型，在放行/拒绝判定上的准确率介于 36% 到 72%（随机为 50%）；某方向的低错误率往往只反映模型的默认倾向。

## 研究对象

- **世界或环境：** prompt injection jailbreak and toxic-content screening; synthetic tool calls
- **智能体：** seven open-weight models used as guardrails
- **观察与动作：** 文本输入与调用方定义选项上的概率分布；以及服务端日志文本对判定的影响。
- **目标与交互协议：** 用七个开放权重模型充当护栏，分别报告两类错误：fail-open（放行被禁动作，属漏洞）与 fail-closed（拦下被允许动作，只是成本）。在提示注入、越狱与有毒内容筛查上评测，并在合成的 agent 工具调用套件上测试六行无关服务端日志文本的作用。

## 论文做了什么

主要贡献是把类型化决策模型作为 agent 护栏的系统评测，分方向报告 fail-open 与 fail-closed，并揭示无关日志文本的影响。

## 证据与发现

作者报告准确率 36%–72%；其中一个模型几乎放行一切，另一个几乎拦下一切；在工具调用套件上，六行不涉及策略的服务端日志文本即可影响判定。

## 可复用模式

护栏评测必须分方向报告错误，并设置“无关文本”对照；只看总体准确率会把默认倾向误读为判别能力。

## 局限性与开放问题

评测为开放权重模型与合成工具调用；真实部署中的输入分布可能不同。
