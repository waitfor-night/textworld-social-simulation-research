## 一句话要点

让 agent 自己撰写可执行 Python 治理规则、投票并生活在其中，检验资源稀缺时能否及时发明出有效制度。

## 研究对象

- **世界或环境：** GovSim-SelfGovern，GovSim 公共池塘资源环境的扩展；五个 agent、固定时间视野的捕鱼公地。
- **智能体：** 撰写法案、接受沙盒校验反馈并投票的 LLM agents。
- **观察与动作：** 抓捕上限、罚金、账户、财政余额、成员资格等可执行规则，以及资源压力下的制度退化。

## 证据与发现

作者报告可执行治理扩大了可行干预空间，但生存取决于能否在制度迅速退化前发现正确机制；财政能力使再分配成为可能，更深的推理和取消民主否决使放逐更可行。作者自述样本量有限（每个模型—游戏单元五个种子），因此对具体模型差异和较小效应的结论功效不足，放逐分析也不构成因果识别。

## 可复用模式

把制度也当作 World 中的可执行对象；agent 生成的不是修辞而是能进入结算流程的规则，并保留沙盒验证与投票记录。

## 局限性与开放问题

单一捕鱼公地环境与小行动 API 限制了制度想象（不能创造法庭或声誉系统）；结论不能直接外推到真实治理或部署的 AI 社会。

## 与本索引的关系

把多智能体规范涌现从“行为收敛”推进到“可执行制度编写”，需要 World 提供规则校验与结算边界。
