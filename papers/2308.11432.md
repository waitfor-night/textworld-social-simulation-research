## 一句话要点

这篇综述以统一框架组织 LLM agent 的构造、应用与评测，是回溯规划、记忆、工具和环境文献的入口，而不是任何机制有效的实验依据。

## 研究对象

- **世界或环境：** 覆盖社会科学、自然科学和工程中的多类 agent 环境。
- **智能体：** 基于 LLM、带规划、记忆、工具和行动模块的自主代理。
- **观察与动作：** 由被综述系统决定。
- **目标与交互协议：** 对领域结构、应用、评测、挑战和未来方向进行系统整理。

## 论文做了什么

作者提出统一的 agent 构造框架，综述不同应用和评估策略，并维护持续更新的参考文献仓库。v7 反映了初版以后快速扩展的领域。

## 证据与发现

证据来自文献归纳而非新的对照实验。该文适合定位共同模块和代表工作；其中的分类、数量和结论需回到被引论文核验。

## 可复用模式

- 用 profile、memory、planning、action 等维度比较系统；
- 将 agent 构造、应用和评测分开整理；
- 用持续更新列表发现候选，再以原始来源入库。

## 局限性与开放问题

领域变化快， taxonomy 会随版本改变；宽泛的“agent”类别容易混合工具调用器、任务代理和社会模拟。综述不能替代 artifact、失败分析或人类有效性证据。
