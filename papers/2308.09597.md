## 一句话要点

ChatHaruhi 将剧本中的角色经历提取为可检索记忆并与改进提示结合，把特定虚构角色模仿从短 persona 描述推进到基于原作证据的回复。

## 研究对象

- **世界或环境：** 中文和英文影视、动漫角色的对话情景。
- **智能体：** 由角色 prompt 和剧本记忆控制的 LLM 聊天代理。
- **观察与动作：** 用户对话、角色设定及检索到的原作片段；输出角色化回复。
- **目标与交互协议：** 模仿特定角色的知识、语气和反应。

## 论文做了什么

论文提出从剧本抽取并检索角色记忆的构造流程，发布覆盖 32 个角色、超过 54,000 条模拟对话的数据集，并比较不同角色控制方案。

## 证据与发现

作者报告自动和人工评测均优于所比较基线，并公开代码与数据。评测主要围绕对话模仿；原作检索可能同时带来角色证据和表面复述优势。

## 可复用模式

- 将角色设定与原作经历证据分开；
- 回复时检索相关角色记忆并保留来源；
- 用跨角色数据检查方法是否只适配单一人物。

## 局限性与开放问题

模拟对话并非真实用户长期互动；虚构角色的“正确行为”常有多种解释。系统没有持续世界状态、行动效果或记忆失效机制。

## 与本索引的关系

ChatHaruhi 是 persona profile 向 evidence-backed character memory 过渡的代表，可与近期长期记忆和角色一致性工作对照。
