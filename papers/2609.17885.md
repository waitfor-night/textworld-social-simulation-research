## 一句话要点

ERPBench 在真实可复现 ERP 系统中以数据库值而非屏幕表象评分，揭示 agent 即使成功保存表单也可能写入错误业务状态。

## 研究对象

- **世界或环境：** live ERPNext 的财务、采购、库存和客户工作流。
- **智能体：** 六个 closed/open screenshot-only computer-use agents。
- **观察与动作：** 截图、GUI 动作、人工审批 gate 和数据库记录。
- **目标与交互协议：** 对任务结果的 ground-truth database values 评分。

## 论文做了什么

构建生产级 harness，将动作置于 human approval 后；benchmark 模式自动运行，并比较 GUI 行为与持久数据库状态。

## 证据与发现

作者报告通用 GUI 能力不能迁移为企业可靠性；部分 agent 最多 85% 运行能保存，但正确值最低仅 3%。

## 可复用模式

交互环境应以权威后端状态评分，区分“动作看似成功”和“状态正确提交”。

## 局限性与开放问题

结果集中于 ERPNext 和 screenshot-only agents；人工审批机制在自动 benchmark 中并未等同真实部署流程。

## 与本索引的关系

为 World State Engine 提供强直接证据：UI/叙事成功不能替代权威状态验证。
