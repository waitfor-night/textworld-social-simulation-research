## 一句话要点

论文在动态网络公共品博弈中分别改变模型、拓扑和提示，显示观察到的合作水平同时受三者影响。

## 研究对象

- **世界或环境：** Watts–Strogatz、Barabási–Albert 和 Erdős–Rényi 动态网络上的 public-goods game。
- **智能体：** Mistral、Llama3、Gemma3 和 Phi3 的同模型或混合模型群体。
- **观察与动作：** 邻接关系、贡献/背叛行动和社会收益 framing。
- **目标与交互协议：** 比较模型架构、网络拓扑与 prompt design 对合作的影响。

## 论文做了什么

在多种网络和人口组成下运行 LLM agent 公共品互动，并统计合作行为。

## 证据与发现

作者报告 Mistral/Llama3 合作率较高、Phi3 更偏背叛，ER 随机网络显著提高合作，society-benefits prompt 也提高合作。

## 可复用模式

社会机制实验至少交叉改变 actor model、graph topology 和 framing，避免把拓扑或 prompt 效应误判为社会规律。

## 局限性与开放问题

属于初步受控博弈；合作指标、网络更新规则和 prompt sensitivity 限制现实外推。
