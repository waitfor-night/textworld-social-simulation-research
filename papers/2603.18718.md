- **标识符：** arXiv:2603.18718
- **作者：** Minhua Lin, Zhiwei Zhang, Hanqing Lu, Hui Liu, Xianfeng Tang, Qi He, Xiang Zhang, Suhang Wang

## 一句话要点

MemMA 用 Meta-Thinker、Memory Manager 和 Query Reasoner 协同记忆写入、迭代检索与失败修复，把记忆周期的前向和后向过程连起来。

## 研究对象

- **世界或环境：** 长期对话 LoCoMo、LongMemEval-S，以及用轨迹记忆测试的 SWE-bench-Verified-mini。
- **智能体：** 负责策略引导、记忆构建、查询推理和回答的多代理组件；编码实验另有基础 coding agent。
- **观察与动作：** 组件读取对话/调试轨迹，写入或检索外部记忆，生成 probe QA，验证证据并执行修复。
- **目标与交互协议：** 在回答前迭代收集相关证据，在提交记忆前把 probe 失败转成修复动作，并以长期任务准确率或代码通过率评估。

## 论文做了什么

论文提出双路径记忆周期：前向路径由 Meta-Thinker 指导 Memory Manager 和 Query Reasoner；后向路径生成合成 QA、验证当前记忆并修复失败。作者将框架插接到三种存储后端，并做组件消融、检索预算和跨任务测试。

## 证据与发现

作者在 LoCoMo 的 GPT-4o-mini/LightMem 组合报告 F1 49.40、B1 38.28、ACC 81.58；在 LongMemEval-S 的 20% 子集报告 ACC 94.0（LightMem 82.0）；在 SWE-bench-Verified-mini 中，within-task 通过率由 vanilla 62.0% 提升到 72.0%，跨任务记忆达 76.0%。这些数字是作者实验结果，尚未独立复现。

## 可复用模式

- 将记忆构建、检索、使用和修复视为一个可追踪生命周期；
- 用合成 probe QA 在写入前检查记忆覆盖和错误；
- 把长期任务失败映射回可定位的记忆修复，而不是只重试最终回答。

## 局限性与开放问题

结果依赖特定存储后端、模型和 LLM 评判设置；LongMemEval 只抽取 20% 样本，额外控制器也带来调用成本。自生成 probe 可能继承错误，社会记忆、权限和跨主体遗忘尚未覆盖。

## 与本索引的关系

MemMA 连接现有 RuleMem、CHIME 与 invalidation 工作，给 `Role Agent Engine` 的记忆写入、检索、验证和修复接口提供可复用分解。
