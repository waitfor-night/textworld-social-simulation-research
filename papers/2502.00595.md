## One-line takeaway

RPGBENCH tests whether an LLM can construct and run a role-playing game with explicit event/state structure and verifiable mechanics over multiple rounds.

## Research object

- **World or environment:** Text RPG scenarios with structured event-state representations.
- **Agents:** LLM game engines interacting with a player or simulated trajectory.
- **Observations and actions:** Natural-language interaction paired with structured state updates and game actions.
- **Goals and interaction protocol:** GC evaluates game creation; GS evaluates multi-round simulation, state updates, and rule enforcement.

## What the paper does

The benchmark combines objective checks of game mechanics with subjective LLM judging. It asks both whether the model can create a playable RPG and whether it can maintain consistency while the game evolves.

## Evidence and findings

The abstract reports that current LLMs can generate engaging stories but struggle with verifiable mechanics in long and complex scenarios. This supports evaluating state transitions independently from narrative quality.

## Reusable patterns

- Define an event-state schema before generating prose.
- Test invariants and rule enforcement after every action.
- Report separate objective mechanics scores and subjective narrative scores.
- Include long-horizon and branching scenarios rather than one-turn prompts.

## Limitations and open questions

An RPG benchmark does not cover open-ended social norms, human calibration, or hidden/private beliefs. LLM-based judging also needs judge agreement and adversarial checks.
