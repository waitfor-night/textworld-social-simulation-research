## 一句话要点

ReAdapt 在每次工具观察后显式更新目标、信念、关系、规范和披露状态，再决定继续、切换、放弃或澄清，减少被表面内容诱导的社交动作。

## 研究对象

- **环境：** 500 个合成社交世界，含友情、关注、互动历史和 feed；生成 1,000 个 reaction selection 与 warm introduction 查询。
- **智能体：** Gemini-3-Flash 的 ReAct 与 ReAdapt agent。
- **观察与动作：** 社交图和内容观察；选择互动对象或介绍桥梁。
- **协议：** 约 53% 查询中表面候选与关系 oracle 冲突；每项任务分层抽取 150 条评测。

## 论文做了什么

维护 `z=(G,B,R,N,D)` 结构化状态；每次观察后执行 typed Adapt，输出 `continue/switch/abandon/clarify` 再选择行动。

## 证据与发现

作者报告 warm-introduction accuracy 从 37% 升至 51%，reaction selection 从 69% 升至 77%；对应 oracle regret 从 0.260 降至 0.152、0.095 降至 0.053。模型、工具和环境保持固定，但只使用单一模型和各 150 条子集。

## 可复用模式

Relationship State 不应只是提示词；每条新证据触发显式 typed update，并允许推翻先前动作政策。

## 局限性与开放问题

社交世界和 oracle 均为合成，状态 schema 可能编码任务答案；尚未测试长程关系、错误观察或真实用户互动。
