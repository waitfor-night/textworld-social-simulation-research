## 一句话要点

共享工作区里的安全风险难以用单一已知位置的攻击覆盖：任务含 115–328 个文件与多个工具，注入可藏在任何文件、脚本与消息中。

## 研究对象

- **世界或环境：** 115 to 328 files with MCP-exposed email calendar chat and code tools
- **智能体：** APEX-Harm six attack categories across finance consulting legal tasks
- **观察与动作：** 长程 agent 在金融、咨询、法律任务中的文件、邮件、日历、聊天与代码执行工具。
- **目标与交互协议：** APEX-Harm 通过 MCP 服务器暴露工具，含六类攻击（静态/动态注入、任务专属脚本替换、攻击者提供的通用脚本），评测攻击成功率、暴露程度与任务表现。

## 论文做了什么

主要贡献是 APEX-Harm：在含 115–328 个文件的共享工作区上评测六类注入攻击的长程安全基准。

## 证据与发现

作者指出大工作区中攻击成功与否与注入位置和 agent 的读取行为有关；具体数值需核对正文。

## 可复用模式

共享 World 即共享工作区：多角色读写同一状态时，注入防御不能假设攻击在已知位置。

## 局限性与开放问题

面向专业 CLI agent；攻击类型集中在提示与脚本注入。
