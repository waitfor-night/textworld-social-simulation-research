## 一句话要点

纯文本摘要未必能支撑后续每个决策；在摘要之后追加一段有界的软记忆 token，让冻结的模型逼近全历史下的续写。

## 研究对象

- **世界或环境：** SummHay and long-horizon agent benchmarks
- **智能体：** frozen Qwen3.8-27B and GLM-5.3-Flash with learned residual memory
- **观察与动作：** 历史与摘要，以及在其后追加的软记忆 token 序列。
- **目标与交互协议：** 训练一个神经记忆网络，在给定历史与摘要时生成软 token，使冻结 LLM 的续写逼近使用完整历史时的续写；token 以摘要为条件并追加在其后，形成沿序列维度的残差连接。在 SummHay 与长程 agent 基准上评测。

## 论文做了什么

主要贡献是训练神经记忆网络生成软 token，使冻结 LLM 的续写逼近使用完整历史时的续写。

## 证据与发现

作者报告 REMORY 在 SummHay 上以约 5.2% 的输入位置改善来源归因、洞见覆盖率几乎不变并逼近全上下文联合得分；在 BrowseComp 与 Terminal-Bench 2.1 上，重复工具输出与工具错误显著减少。

## 可复用模式

压缩应保留“让后续决策与原历史一致”的可学习残差，而不是只保留可读摘要。

## 局限性与开放问题

需要训练记忆网络；评测集中于压缩质量与工具调用行为，未直接测量角色一致性。
