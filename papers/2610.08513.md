# Wiki-Talkie: Multilingual Benchmarking of Persona-Based Agents on Real-World Discussions

- **标识符：** arXiv:2610.08513
- **作者：** Dennis Fucci, Andrea Bacciu, Dong Liu 等
- **日期 / 版本：** 2026-10-06 提交，版本 1（2026-10-08 收录）

- **主领域：** RPL — 角色与人格
- **相关性：** `core`

- **观察日期：** 2026-10-08
- **置信度：** `high`

## 一句话要点

用真实用户社区而不是虚构人物作为 persona 依据，并在多语言上检验行为保真度。

## 研究对象

- **世界或环境：** Wikipedia Talk pages across five languages
- **智能体：** persona-grounded agents
- **观察与动作：** 真实用户的自述、社会人口属性与行为交互特征，以及 agent 在对话中的表现。
- **目标与交互协议：** 构建来自 Wikipedia 讨论页的五种语言（德、英、西、法、意）数据集，persona 取自真实用户社区，评测 agent 的交互保真度。

## 论文做了什么

主要贡献是五种语言的维基讨论页数据集与取自真实用户社区的 persona，用于评测交互保真度。

## 证据与发现

作者指出现有数据集依赖虚构 persona 且语言有限，缺少跨人群的行为保真评测基础。摘要未给出具体数值。

## 可复用模式

persona 评测应说明其依据来自真实人群还是构造人设，并报告跨语言的一致性。

## 局限性与开放问题

Wikipedia 讨论页的参与者不代表一般人群；摘要未报告多语言结果差异。
