# Does Your Agent's Memory Survive a Model Upgrade？

- **来源类型：** 官方论文/预印本
- **作者或组织：** Ankit Goyal、Jaideep Ray
- **发布于：** 2026-09-04（arXiv v1，under review）
- **观察日期：** 2026-09-07
- **规范链接：** https://arxiv.org/abs/2609.05339
- **相关论文/项目：** [arXiv HTML 全文](https://arxiv.org/html/2609.05339v1)
- **相关性：** `core`
- **置信度：** `medium`

## 观察到的内容

论文在 48 个合成历史、两个 10B 以下开放权重模型上比较长上下文原文、RAG 分块、自然语言 NOTES 和固定 schema 知识图谱四类记忆。固定 schema 在作者的换写入模型实验中几乎不变；NOTES 对迁移方向高度敏感，混用新旧 embedding 只获得部分收益，保留原始历史比只修复压缩笔记更能恢复性能。

## 证据与佐证

arXiv 摘要给出 KG-fixed、NOTES、混合索引和修复实验的具体差异（包括 +0.0004、+9.91/-13.28 个百分点等）。论文标注为 under review，使用合成历史和有限模型，当前未发现公开代码/数据仓库，因此数字应视为待复核的作者报告。

## 为什么重要

社会代理升级模型时，旧记忆可能包含关系、私有状态和事件证据；这项研究把“记忆可迁移性”从检索准确率问题拆成表示耦合、embedding 隔离和证据可恢复性问题。

## 后续跟进

用带私有信息和矛盾事件的文本社会世界做方向性迁移测试，分别测量信息损失、检索失败和隐私泄漏；等待代码后固定模型、embedding 版本与迁移方向。
