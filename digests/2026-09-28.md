## 最直接关联当前最小角色设计的四篇

- [AgentWorld](../papers/2609.31590.md) `2609.31590`（COLM 2026）：基于开源 MMORPG 引擎的沙盒，100 个人工标注任务，50+ 交互轮、3–20 个非对称角色，并要求追踪行动对结果的因果贡献（CCE）。最好模型任务成功率 52.0%。这为多角色阶段的 World 提供了“共享状态 + 因果依赖”的具体形态。
- [Situated Identity Test](../papers/2609.22195.md) `2609.22195`：论文证明仅条件化于压缩 profile 的 policy 在 m 条冲突人生谱系上的 situated validity 上界为 1/m。这给出角色身份的**可判定验收标准**：既要知晓已记录经历，也要对未经历内容保持恰当无知。仓库 `openkedge/sitbench` 公开。
- [Epistemic Admission](../papers/2609.30813.md) `2609.30813`：重复出现的声明不等于独立证据；按来源类型门控可把错误采纳降到 0.06–0.09，但没有任何非 oracle 策略能一致拒绝复制、改写与“声称权威”的假声明；一条无争议假信念进入共享记忆后，消费端在 0.97–0.99 的探测中把它当作事实。
- [MoM: Memory of Memory](../papers/2609.25054.md) `2609.25054`：记忆要回答“当前成立什么”，写入时提交现值同时保留被替换值；作者报告陈旧回答率 19.4%→10.9%，修订链上 100% 而查询时读取跌到 25%。

## 角色、人格与模拟保真

- [Deep Persona](../papers/2609.22255.md) `2609.22255`：表达层、潜在信念层、核心动机层三层人格，配合“脚本化确定性 + 有限能动性”；作者自陈评估主要依赖 LLM-as-judge。
- [Truth for Believable AI](../papers/2609.26035.md) `2609.26035`：把表达不确定、来源门控与信念修订做成行为层；合成仪器通过全部检查，真实模型上预注册的表达保真与来源边际检验**未通过**，按回答 token 概率门控排序甚至低于随机。
- [Do Synthetic Personas Predict Real Audience Response?](../papers/2609.25010.md) `2609.25010`：以 Upworthy 真实 A/B 点击率为金标准时，十人 persona 面板预测有效性反而低于无 persona 基线（τ 0.361 vs 0.084），并在三个拆分复现。
- [Thinking Less to Simulate Better](../papers/2609.30563.md) `2609.30563`：8 名参与者、68 条帖子的个体级保真研究；直觉式提示保真最高，并把个体差异压缩从七倍降到三倍，但作者明确不能推断总体参数。
- [Understanding Reliability in LLM-based Human Behavior Simulation](../papers/2609.25066.md) `2609.25066`：个体级 R1 提升不能可靠迁移到群体级 R2，两者甚至可能反向变化；覆盖增加到约 50–100 个体后 R2 稳定但系统性偏差仍在。
- [Partner-Specific Affective Precision](../papers/2609.24876.md) `2609.24876`（IWAI 2026）：关系特异置信主要改变政策果断程度而非推断内容，且置信修订会滞后于对方变化。

## 世界结构、制度与叙事控制

- [WorkWorlds](../papers/2609.23806.md) `2609.23806`（v2）：先固定组织世界状态、再引入任务；任务级策展把证据获取率从 72.8% 提到 90.4%，而“获得证据后通过率”几乎不变——差异发生在 agent 取得证据之前。这直接约束了观察文本不得按任务反向裁剪。
- [GovSim-SelfGovern](../papers/2609.22600.md) `2609.22600`：让 agent 撰写可执行 Python 治理规则并投票生活在其中；作者自述单一捕鱼公地、每单元仅五个种子，放逐分析不构成因果识别。
- [Financial Fragility in Societies of LLM Agents](../papers/2609.30940.md) `2609.30940`：七个 LLM 在无破坏指令下仍有 77% 挤兑、83% 债务滚动 episode 失败；三种稳定机制都有效，共同模式是承诺须在防御行为自我强化前较早形成。
- [Detective Games via Structured Knowledge Trees](../papers/2609.23043.md) `2609.23043`：三 agent 流程让嫌疑人只披露叙事状态允许的信息；作者报告关键幻觉下降 64.78%，同时承认机制约束带来可用性代价。

## 对当前实现与研究的直接影响

1. World 应先于任务被实例化；不要把任务答案写进初始观察（WorkWorlds）。
2. 角色身份验收加入“恰当无知”一项：编造未经历的传记属于身份错误（SIT）。
3. 共享记忆的准入由来源谱系决定，重复与改写不得累加为独立确认（Epistemic Admission）。
4. 记忆条目需要现行/被替换状态；被替换内容保留为谱系而非重新参与冲突（MoM、EGMEMORY）。
5. 多角色阶段要显式记录行动—结果因果依赖，而非只统计各自任务完成率（AgentWorld）。
6. persona 相关结论必须区分“与 profile 自洽”和“与真人一致”，并保留无 persona 对照（2609.25010、2609.30563）。
7. 表达层面的不确定性语气不能替代事实边界（Truth for Believable AI 的负结果）。

所有数值均按作者报告记录，不视为独立复现。预先存在的 `tmp/` 保持未跟踪。
