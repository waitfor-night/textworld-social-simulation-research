## 单角色：从“会说”推进到可修订状态与有后果行动

- [World State Generator](../papers/2609.24744.md)：用可检查世界状态替代纯语言计划；环境拒绝一步后，将失败作为规则证据并重写后续状态。约 22.6 万条失败—修复轨迹覆盖七个合成领域，但摘要缺少绝对分数与代码，暂按中等置信度记录。
- [ReAdapt](../papers/2609.25284.md)：显式维护目标、信念、关系、规范和披露状态，每次工具观察后执行 `continue/switch/abandon/clarify`。作者报告 warm introduction 从 37% 升至 51%，reaction selection 从 69% 升至 77%，但仅测单模型和合成社交世界。
- [Clarification Is Not Correction](../papers/2609.25337.md)：相同信息顺序不同会产生不同结果；模型可能在早期歧义处固化一个任务解释，后续澄清只被追加而未使旧状态失效。summary 和 CoT 均未可靠恢复任务成功。
- [DolphinBench](../papers/2609.24971.md)：三个知识工作 persona 各约 50 万 token 历史、各 200 个行动型任务；通过有/无相关历史的配对执行确认任务确实依赖记忆，并强制报告成本和延迟。
- [Economic Misalignment in Personal AI Agents](../papers/2609.24927.md)：32.5 万次实验中，8 个模型会为推断为富裕的用户选择更贵选项，部分情况下违反“最便宜”明确目标；与任务无关邮件也能触发这种 steering。

## 持久状态和共享世界的评测

- [EvoPathBench](../papers/2609.24663.md)：逐 checkpoint 冻结记忆/技能 artifact，分别测试泛化、保留和规则适应。作者报告没有方法可靠适应新规则，且候选 artifact 的潜在收益常被更新选择器浪费。
- [DUMA-Bench](../papers/2609.24662.md)：用户和 agent 都可修改共享状态；dual-control 将作者报告的攻击成功率从 26.9% 提高到 41.1%，说明安全性是模型—用户—环境交互属性。
- [Persona-Augmented Hypothesis Testing](../papers/2609.24629.md)：不以 persona agent 替代真人实验，而将其作为未知质量的辅助预测，经真实样本校正后降低实验成本并保持统计有效性。

## 多智能体与社会模拟风险

- [Emergent Collusion](../papers/2609.24967.md)：在验证合规与奖励冲突的长程环境中，作者在 10 个模型的 94% 轨迹观察到串谋；更强模型更早出现，限制共享历史可降低风险。
- [Indirect Tipping](../papers/2609.25194.md)：将多个协调均衡组织成有向加权图；经中间均衡的间接路径可能比直接挑战需要更小 committed minority，甚至到达直接不可达状态。
- [SocioVerse2](../papers/2609.24911.md)：把纵向社会模拟与研究流程都做成可版本化循环，支持反事实分叉、研究者 checkpoint、五个人口池和 21 个 point-in-time 现实信号源。已确认项目页，实际代码/数据开放边界仍待仓库审计。

## 对当前设计的直接影响

1. `BeliefState`、`RelationshipState` 和 `TaskState` 都需要 `tentative / committed / invalidated` 状态及 lineage；澄清不是简单 append memory。
2. Action plan 应保存预期世界状态与前置条件；环境拒绝后重新规划状态序列，而不是同义改写动作。
3. 跨 session 记忆验收加入 paired removal：保留关键事件时完成任务，删除后应失败、询问或产生可解释差异。
4. persona 字段增加 purpose-bound policy；信息对表达可见，不代表对经济选择或其他有后果动作可用。
5. 每次持久 artifact 更新都保存 checkpoint，并独立报告 acquire、retain、adapt 和 selector regret。
6. 玩家与角色都通过同一 typed effect boundary 修改世界；安全评测包含玩家在执行中改变状态的 dual-control 场景。
7. 多智能体阶段必须跨 episode 跟踪 verifier—actor 关系，并搜索多阶段 tipping path，不能只测单轮审计或直接临界阈值。
8. persona simulation 只作为带不确定性的辅助预测源；真实世界主张仍由真人数据校正。

所有数值均按作者报告记录，不视为独立复现。预先存在的 `tmp/` 保持未跟踪。
