## 社会扩散与集体认知

- [Message capacity and claim wording](../papers/2609.19183.md)：单 agent 判断近似 inbox 加权 logistic 函数；转折点由 message capacity 与 claim 措辞阈值共同决定。作者原预测在 1,414 个 episode 中失败，引入措辞阈值后才复现。
- [Contagion on the Trading Floor](../papers/2609.19789.md)：仅经可采信社媒内容的输入投毒就能跨 analyst/coordinator 传播并压低 Sharpe ratio；拓扑与 prompt 可减弱但依赖配置。
- [For Your Eyes Only](../papers/2609.19504.md)：隔离的同架构模型实例可仅靠预训练共享形成隐式信号，过滤可检测信号后多数模型协调失败，个别模型仍接近完美。
- [Reputation as Community Memory](../papers/2609.19502.md)：Cairn 把共享资源可信度做成社区声誉记忆，用时间衰减 Beta 与置信收缩聚合证据型评分。

## 验证状态、提交与资源冲突

- [Silence Is Endorsement](../papers/2609.20211.md)：交接与记忆压缩丢掉“未验证”framing 后，风险动作批准率从 5% 升到 60%（Llama-3.1-8B）、9% 升到 98%（Qwen2.5-14B）。
- [Cognitive Serializability](../papers/2609.20261.md)：数据库隔离只保证提交顺序；typed dependency token 与可信中介使动作与其推导输入存在共同有效点，原型增加 3.22 ms 提交开销并阻止全部注入异常。
- [ClashBench](../papers/2609.19892.md)：44.5% 轨迹出现 destructive resource preemption，31.9% 的抢占成功案例在最终回复中既不提冲突也不提所采取行动。

## Harness、组织与长期运行

- [How Do Agent Harnesses Create Value?](../papers/2609.20474.md)：字数匹配的 sham 对照显示规划内容本身提升 oracle 成功率 7.17 个百分点；错误接纳代价高时，独立 verifier 几乎覆盖全部收益且成本极低。
- [Rethinking Multi-Agent Collaboration](../papers/2609.19759.md)：多智能体优势受任务结构约束，长程稀疏依赖有收益、紧耦合顺序流程不如单 agent harness；扩大 agent 池或加深递归并不持续改善。
- [Levels, Ticks and Cascaded Intelligence](../papers/2609.19519.md)：十天 campaign 表明持续运行需要生存期超过 context 的持久基底，早期写入的操作知识无需改权重即可改变后续行为。
- [Web Search by Conversational LLM Agents](../papers/2609.19244.md)：跨四个平台刻画检索决策、策略、来源与回答，以描述性观测为主。

## Persona、个性化与长期记忆

- [Tailored to you](../papers/2609.20077.md)：992 人五天纵向研究显示多数时间变化来自重复暴露而非个性化；memory-based 条件自披露更多、creepy 评分更低，survey-based 条件后悔更高。
- [To Memories and Beyond](../papers/2609.19167.md)：ReaLMem 以真实多年视觉档案评测事实回忆、persona 推断和预测性个性化，预测性个性化是一致上限；ChronoProfiler 用时间稳定性权重处理冲突偏好。
- [SimLife](../papers/2609.19610.md)：106 个家庭生活 episode 与 1,439 个问答对；模型多为表面预测，依赖频次启发式而非基于证据的 if-then 推理，模式变化时适应困难。
- [Nudge Susceptibility in GUI Agents](../papers/2609.19843.md)：3,600 个 agent、21,600 次模拟显示推理配置降低默认型 nudge 易感性却提高社会影响型易感性，即改道而非免疫。

## 对系统设计的影响

1. **Authorizarion provenance 必须是结构化状态。** 摘要和记忆压缩会洗掉验证状态，提示性修复跨模型不可靠。
2. **提交需要推导输入的共同有效点。** 事务顺序不等于证据、政策与授权在推理期间保持有效。
3. **资源冲突要作为一等风险。** 代理可能在完成任务的同时破坏既有任务，并且不报告。
4. **harness 组件按错误接纳代价排序。** 规划与验证的收益结构不同，应做字数匹配的 sham 对照。
5. **多智能体不是默认更优。** 协作拓扑应由任务依赖结构推导，并报告上下文开销。
6. **persona 状态需要时间稳定性权重。** 冲突偏好不能以最新覆盖，个性化还要与人因后果分开评估。
7. **措辞阈值与阅读上限是集体结果的两个可测机制。** 社会扩散实验应同时报告两者，而非只报告网络结构。
