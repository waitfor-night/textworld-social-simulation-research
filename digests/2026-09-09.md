# 历史回填：文本环境谱系（2018–2021）

- **日期：** 2026-09-09
- **范围：** 执行 `docs/repository-development-plan.md` 批次 1
- **方法：** 从 autonomous/language-agent、role-playing 与 social-simulation 综述回溯共同引用的环境论文，再以 arXiv 规范页、论文 HTML 和官方代码仓库核验。

## 本轮新增

- [TextWorld](../papers/1806.11532.md)：可生成文本游戏、显式状态、转移与奖励，建立可控的泛化实验底座。
- [Jericho](../papers/1909.05398.md)：用人工互动小说补足生成环境的语言、常识与长程复杂度。
- [LIGHT](../papers/1903.03094.md)：首次把 persona、地点、对象、对话、动作和情绪系统地放入同一幻想文本世界。
- [ALFWorld](../papers/2010.03768.md)：把 TextWorld 高层动作与具身环境对齐，支持抽象策略向具体执行迁移。

## 形成的环境谱系

```text
TextWorld：可控生成 + 权威状态
  ├─ Jericho：人工世界的语言与常识复杂度
  ├─ LIGHT：身份、对话与世界动作共同 grounding
  └─ ALFWorld：抽象文本策略 ↔ 具体具身执行
        ↓
近期 LLM agent / belief-based world model / text world model
```

这四项工作共同说明，文本环境不是聊天记录：它至少需要状态、动作、转移、反馈和任务协议。LIGHT 进一步加入身份与局部社会上下文；ALFWorld 则显示抽象 rollout 和最终执行应分开评估。

## 对当前设计的影响

1. `World State Engine` 应维护独立于叙事文本的权威状态和动作合法性。
2. `Role Agent Engine` 的身份必须与地点、对象、关系和动作能力共同约束输出，不能只靠 persona 文本。
3. 世界模型评测应同时包含可控生成任务和人工复杂环境，避免只适配单一模板。
4. 高层计划成功、动作编译成功和底层执行成功必须分开计分。

## 第二批：架构与社会智能体基线

- [ReAct](../papers/2210.03629.md)：把推理、动作和环境观察组成可审计闭环。
- [Generative Agents](../papers/2304.03442.md)：用经历流、检索、反思和计划支持持续小镇生活。
- [SOTOPIA](../papers/2310.11667.md)：将角色背景、私有社会目标、人类参照和多维评分组合成互动评测。
- [Concordia](../papers/2312.03664.md)：以组件化代理和 Game Master 连接自然语言意图与生成式 ABM 环境推进。
- [CAMEL](../papers/2303.17760.md)：用角色提示与结构化对话协议实现早期多智能体协作。
- [Voyager](../papers/2305.16291.md)：把长期记忆落成可执行技能库，并利用环境错误迭代修正。

## 两批合并后的设计链

```text
显式环境状态（TextWorld / Jericho / ALFWorld）
  → 推理—行动—观察（ReAct）
  → 身份化语言与动作（LIGHT / SOTOPIA）
  → 记忆、反思、计划（Generative Agents）
  → 多角色通信（CAMEL）与可执行技能（Voyager）
  → 环境裁决与生成式 ABM（Concordia）
```

这条链为近期论文提供了更清晰的历史参照，但仍缺少系统性的综述/反证条目，以及 2024–2025 平台化、规模化和真实人类校准之间的过渡。

## 第三批：综述入口与可靠性反证

- [Autonomous Agents Survey](../papers/2308.11432.md)：规划、记忆、工具、应用和评测的宽口径引文入口。
- [CoALA](../papers/2309.02427.md)：用记忆、内部/外部动作与决策循环组织 agent 架构。
- [Role-Playing Language Agents Survey](../papers/2404.18231.md)：区分人口统计、既定角色和个体化 persona。
- [Social Simulation Survey](../papers/2412.03563.md)：区分个体、情景和社会三个模拟层级。
- [TrustSim](../papers/2410.23426.md)：表明角色模拟一致性与通用模型能力并不强相关。

综述只作为 taxonomy 和引文入口，不当作机制有效证据；TrustSim 则提供“更强模型不自动带来更可靠模拟”的约束。

## 角色扮演历史补充

沿角色智能体综述的引文继续补入 7 篇，形成更完整的演化链：

- [Persona-Based Neural Conversation Model](../papers/1603.06155.md)：隐式 speaker persona 与说话者—听者关系；
- [PERSONA-CHAT](../papers/1801.07243.md)：显式 profile 条件和众包人格对话；
- [ChatHaruhi](../papers/2308.09597.md)：从剧本抽取、检索角色经历；
- [RoleLLM](../papers/2310.00746.md)：角色知识、风格、指令数据与开放模型微调；
- [Character-LLM](../papers/2310.10158.md)：将人物 profile、经历和情绪变成可训练角色代理；
- [InCharacter](../papers/2310.17976.md)：通过心理访谈评测人格保真度；
- [LIFECHOICE](../papers/2404.12138.md)：通过文学人物决策点评测 persona-driven decisions。

由此得到的角色谱系是：

```text
隐式 speaker embedding
  → 显式 persona statements
  → 原作/经历记忆与检索
  → 角色条件训练
  → 知识与风格评测
  → 人格访谈评测
  → 决策一致性评测
```

关键结论是：角色扮演不能只用语言风格衡量。至少要分开角色知识、表达风格、人格、经历记忆、关系和行为决策；进入文本世界后，还需继续测行动后果和长期连续性。

## CoSER 与 Xintao Wang 研究线

[CoSER](../papers/2502.09082.md) 是这条角色研究线的中心节点：它从 771 本书整理 17,966 个角色，将场景、经历、原始对话、动作和内心思考组合成 given-circumstance acting 数据，并发布 8B/70B 模型和评测。

按研究问题而非简单作者列表追踪，其直接谱系为：

```text
InCharacter：心理访谈评测人格
  ├─ RolePersonality：用心理量表构造人格指示训练数据
  ├─ LifeChoice：用文学决策点测行为一致性
  └─ CoSER：文学场景 + 多角色表演 + 经历/内心
       ├─ ROLETHINK：检索经历、反应和动机，评测内心推理
       ├─ HER：在 CoSER 上加入双层思考、奖励模型和 RL
       └─ HumanLLM：把静态 persona 推进到多心理模式因果交互
```

另有 [MINDECHO](../papers/2407.05305.md) 将同一套个体化训练/检索思路用于现实 KOL；它有明确的同意、冒充、隐私和声誉边界，因此只列为 adjacent。作者同名检索会混入大量视频生成论文，本轮只收录能由共同作者、主题和引用链确认的角色扮演工作。

对文本世界项目最值得复用的不是一个更长 persona prompt，而是：将公开对话、私有内心、动作、经历记忆和权威场景分层；用多角色同场约束检验一致性；并防止同一文学数据在训练、检索和评测之间污染。
