## 世界状态与长程记忆

- [World Model Science](../papers/2609.17419.md)：逐步对齐 agent-implied state 与 benchmark-grounded state；局部动作仍合法时，全局状态保真可能已经失败。
- [LSREP](../papers/2609.16730.md)：以 ordered replay、52 个 checkpoint、动态 reference 和 mechanism audit 评测持续记忆；其 ICE v2 案例在 LongMemEval 上显著弱于 vector-RAG，作者没有把成本降低包装成质量提升。
- [EchoPath](../papers/2609.16635.md)：将 artifact-validated GUI trajectory 编译成有 typed precondition、参数、证据与生命周期的可调用记忆，重放前重新验证当前环境。

## 多智能体认知、通信与网络

- [ToMAS](../papers/2609.16986.md)：把真实多代理 FC2 失败转换成 partner-state 题；训练 pilot 参数更新近乎为零，作者明确结论为未观察到训练效果。
- [Cheap Talk Stabilizes Strategic Interaction](../papers/2609.16270.md)：非约束性通信通常降低重复博弈中的策略漂移，但效应高度依赖模型、历史和语境。
- [Social Behavior Among Autonomous AI](../papers/2609.16013.md)：在动态 public-goods networks 中交叉改变模型、网络拓扑和 prompt，提示合作率不是单一 agent 属性。

## 动作准入

- [Cognitive Admission Control](../papers/2609.16313.md)：将授权与 readiness 分开，要求 typed action 按风险满足证据类别、新鲜度、scope 和 witness independence 后才签发执行证书。

## 对系统设计的影响

1. **世界模型评测要逐步比对 Belief 与 Authority。** Terminal reward 无法发现“局部动作尚可、全局状态已错”的阶段。
2. **记忆质量必须纵向重放。** 每个 checkpoint 的正确答案会随新增、修订和过期而改变；架构声称的机制还要用轨迹证明真的触发过。
3. **可复用技能是经过验证的 typed execution，不是经验摘要。** 保存 precondition、参数、provenance 和生命周期，当前状态不兼容时拒绝重放。
4. **多代理 ToM 应来自真实失败轨迹。** 但数据转换 pipeline 跑通不等于训练有效，必须核验参数更新与 matched-domain evaluation。
5. **通信和拓扑是独立机制变量。** 合作或稳定性必须跨模型、消息历史、网络和 framing 做配对比较。
6. **动作许可不等于动作已准备好。** 高风险提交需证据准入、dispatch guard、证书和 replay protection。
