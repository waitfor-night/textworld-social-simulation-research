## 本轮新增

### 社会模拟、组织与协作

- [ORCH](../papers/2609.11737.md)：用并行/前置依赖建立异质具身团队层级，显示组织结构可显著影响集体表现。
- [Town Economy](../papers/2609.11108.md)：100 个 agent、最长 26 周的守恒货币经济；短期价格/工资刚性与长期财富动态明显不同。
- [Convention Gap](../papers/2609.11489.md)：比较字面信息预测与实际失败，测量人类—AI 合作中的隐式约定兼容性。
- [ProMediConv](../papers/2609.11101.md)：把法律调解表示为策略、阶段和当事方状态转移，而非只测最终回复。

### 角色、记忆、规划与自进化

- [KuaiRP](../papers/2609.11127.md)：角色知识注入、规则奖励和蒸馏，并显式处理通用 agent 能力遗忘。
- [Environment-Probing Memory](../papers/2609.11060.md)：让记忆 curator 用最小权限只读工具核验候选记忆。
- [MAPLE](../papers/2609.11636.md)：跨自然语言变更保留可执行优化程序、已接受计划和候选解。
- [COBRA-Skills](../papers/2609.11682.md)：用 contextual bandit 在有限执行预算下选择和演化技能。
- [Ecdysis](../papers/2609.11677.md)：聚合跨任务失败，区分模型适配与 harness 系统修复。

### 评测完整性与外部有效性

- [BenchShield](../papers/2609.11028.md)：用生命周期模型和基础设施证据检测越过评分边界的 reward hacking。
- [MCP Registry Audit](../papers/2609.10962.md)：概率抽样显示真实 MCP server 的启动失败和工具分布与精选 benchmark 显著不同。

## 研究判断

1. 多智能体能力不仅来自模型和提示，还来自组织、依赖和隐式约定；这些应成为可消融状态。
2. 长期社会模拟需要守恒量、签名账本、干预和多时间窗，否则短期稳定容易被误判为长期规律。
3. 记忆与规划应查询权威环境并保留可执行状态，语言摘要只能作为视图。
4. 自进化技能和 harness 必须保存版本、失败证据和修改原因，避免把模型缺陷固化为系统规则。
5. benchmark 需审计真实工具可运行性、抽样偏差和 reward boundary；只报告已清洗成功环境会高估有效性。
