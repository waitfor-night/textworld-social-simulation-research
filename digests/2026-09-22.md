## 社会模拟必须先证明“模型能生成目标现象”

- [Testing, not presuming, adequacy](../papers/2609.24012.md)：将参数可识别性、prior-predictive reachability、posterior-predictive localization、诊断修复和 held-out audit 串成校准协议。真实二手奢侈品网络在四个 cell 中均超出模型可达范围；修复后仍不充分。它提醒我们不能把表面网络相似或参数拟合当作模拟有效性。

## 角色行为与主动询问

- [Reactive Character Behaviors](../papers/2609.24025.md)：用 DSL、符号枚举和 agent 高层草图合成紧凑可编辑的连续游戏角色策略。它不研究 persona，但支持把有后果行为落为可执行政策，而不是由散文直接修改世界。
- [CIGAsk](../papers/2609.24290.md)：联合学习何时澄清与如何提问；Counterfactual Information Gain 衡量用户回复对正确答案的增益，非对称歧义奖励决定 ask/answer。开放世界没有 gold label，因此第一版更适合借用其评测思想，而不是立即复现训练。

## 记忆：写入、检索与实际使用是三个问题

- [Jev-Mem](../papers/2609.23986.md)：轻量 System-One 控制器负责类型、关系、路由、预算和停止，LLM 只做复杂推理与合成；作者报告 LoCoMo judge 0.777、构建 6.6× 加速、查询延迟降低 36.7%。
- [MemCalib](../papers/2609.24259.md)：分别测量记忆 over-use 与 under-use，并用原子级反事实消融分配训练信用。它补足此前笔记的缺口：正确检索不代表模型会赋予记忆正确影响。

## 权限、执行证据与持久修改

- [Self-Healing Harness](../papers/2609.24130.md)：候选行为规则先临时执行，只有改善触发失败且不过度回归保护案例时才持久化。被 replay 拒绝的 383 个规则中，211 个改善局部失败却破坏既有成功案例。
- [APEXA](../papers/2609.24165.md)：确定性工具 guard 禁止展示无执行记录支持的结果；部署中曾捕获模型编造未运行命令的完整校准报告。模拟设备控制对抗测试为 0/200 违规，对照 safety prompt 为 15/200。
- [ActGov](../papers/2609.24446.md)：在每次工具效果前检查 task-scoped authorization 和适用 policy，并用 SMT counterexample checking 检查政策更新。它与 evidence/readiness gate 互补而非替代。

## 对最小主动角色的影响

1. `MemoryWrite → RetrievalControl → MemoryUseGate` 分成三个可独立测试的步骤；第一版用固定规则即可，不需要训练新的 memory controller。
2. `ask` 既要有触发条件，也要评估问题能否真正减少决策不确定性；记录 ask cost、获得的信息和后续行动改变。
3. 身份、承诺或策略更新先进入 provisional state，经配对 replay 和 protected scenarios 后才升级为跨 episode 持久状态。
4. 所有“动作成功”叙述必须引用 committed event 或 tool receipt；没有执行证据时只允许返回明确 non-result。
5. authorization 与 readiness 分离：角色有权执行某动作，不代表当前证据足以执行。
6. 社会模拟扩展前先做 reachability 与 held-out statistic：若目标宏观现象不在简化世界可达域内，继续调 prompt 没有意义。
