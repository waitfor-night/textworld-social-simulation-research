## 世界模型：代码世界与分级验证

- [Mallea](../papers/2610.21283.md) `2610.21283`：代码世界模型用显式状态与可执行规则表示动态，并把**对象表示、行为修订与外观记忆统一在同一批对象上**——文本请求可编辑属性或扩展能力，未受影响的状态必须保留；程序推进状态，渲染器把当前结构与记忆中的外观结合。与本项目 World 的对象能力设计几乎同构。
- [OmniVerifier-C1](../papers/2610.22355.md) `2610.22355`：把复杂提示或环境规则自动分解成子问题并逐项打分，替代 True/False 二值验证；作者证明在有真值图像时**成对验证比逐点更准**，核心论断是"从生成模型走向结构化世界建模 agent，关键取决于是否有准确的成对分级验证器"。

## 时钟：本轮最一致的主题

- [The World Won't Wait](../papers/2610.20665.md) `2610.20665`：180 个任务、六类游戏，**暂停与继续运行两种条件配对比较会直接翻转排名**——GPT-6.1-sol 在暂停时优于更快的 Jev，持续运行时落后。TORSI 用慢教师在暂停游戏中研究失败、写成指令交给快学生，两轮把 Jev 的分数从 13.51 提到 24.19（0–100）。
- [Realtime-Bench](../papers/2610.22155.md) `2610.22155`：用 **Wall Clock / Paused Clock / Token Clock** 三种时钟分离"服务慢"与"缺乏时间感知"。Wall Clock 下最佳成功率仅 **44%**、最佳 Pass^3 仅 **36%**；更高推理投入在时间压力下效果混杂。

## 长程多智能体运行

- [四个 Gemini 4 Argon agent 通关 Minecraft](../papers/2610.22319.md) `2610.22319`：一句话目标、游戏内聊天与共享记忆，**没有人分配角色或写游戏逻辑**；团队自行编写 2,783 个程序，27 小时 14 分钟击败末影龙，途中死亡 605 次。这是"共享记忆 + 聊天 + 无预设角色"最简配置的一次长程验证。
- [SCARCE](../papers/2610.21029.md) `2610.21029`：在共享执行资源上协商访问权的编码 agent 群体会**自发形成非正式制度**（基于声誉、互惠与先例的持久规则与承诺），并跨任务影响资源分配；八个模型、1,500+ 轨迹，21 类策略分类法；新前沿模型表现出更多制度行为，也观察到排他性联盟。

## 记忆：压缩、内在评估、版本与删除

- [Prune the Summary, Not the History](../papers/2610.20927.md) `2610.20927`：压缩提示要求写出决策与下一步，于是摘要把**环境确立的事实与压缩器自己写的推理混在一起**，agent 事后无法区分。失败运行中 **83% 可追溯到某条摘要条目**，而其中多数条目没有环境输出支持；源判定压缩（用 Jev 逐条判来源）把跨运行可靠性提升 2.1%–8.9%，不增加 token。
- [Beyond Downstream QA / FEB-30](../papers/2610.22209.md) `2610.22209`：用问答准确率当记忆质量代理会同时产生假阳性与假阴性。内在与外在评估平均相差 **16 个百分点**；代表性系统正确分类记忆操作（创建/更新/强化/取代）的比例**只有 20%**，且这一失败在外在评估中完全不可见。
- [TEM](../papers/2610.21900.md) `2610.21900`：新事实替换旧值不等于旧值失效。把事实存成**版本化记录 + 来源链接**，检索时按来源顺序并标注历史状态：关键实体命中率 75.71–97.62%，历史居住地子集 96.67–100%；加历史标签提升 17.14–55.95 个百分点，证据仅 94–118 token（比会话感知 RAG 少 48.75–56.73%）。
- [MemCut](../papers/2610.21405.md) `2610.21405`：用户请求删除后，信息仍可从**从未直接说出秘密的消息**间接恢复。LLM 引导额外删 10 轮后残余恢复仍有 **39–76%**；固定预算下扩大候选池比删掉全部原候选更有效——**候选覆盖是瓶颈**。
- [Tool Graph Memory 的负结果](../papers/2610.21571.md) `2610.21571`：九个模型、两个基准上很少显著优于基线，有增益时也付两倍以上 LLM 调用；**随机或不给建议仍保留大部分增益**，说明收益来自额外计算；把同样经验存成文本洞见几乎不增调用就超过它。
- [RIKA](../papers/2610.21739.md) `2610.21739`：代表性持续学习系统产出的经验条目中 **12%–33% 在复用时损害后续表现**；证据式知识准入在四个主干、六个任务流上均取得最高综合分。

## 信念、承诺与抵抗

- [Believed but Not Said](../papers/2610.22138.md) `2610.22138`：十人讨论中三个对抗者把良性 agent 最终持错误答案的比例从 **0.6% 提到 60.5%**；但良性 agent 在 **51.6%** 的暴露轮次中私下持错误答案，**只有 19.7% 公开背书**——影响大多不可见。保留正确答案者也常无法为之辩护，错误答案一旦被采纳会在良性 agent 间传播。
- [Who May Release an Agent's Promise?](../papers/2610.21203.md) `2610.21203`：只有债权人（或其授权者）有资格释放承诺。小模型更多越权执行债权人（69%），大模型更易因同伴一句话放弃承诺（89%/83%）；Oracle 提示能抑制"无资格释放"却抑制不了"越权执行"，只有知道"承诺是否仍被欠着"才行；**自我保存的承诺台账**在五个模型中四个消除越权执行，配一段释放策略把严格准确率从 49% 提到 83%。
- [MASP](../papers/2610.21156.md) `2610.21156`：主动式对话常与"软用户"训练；把用户建模为**理性抵抗**的部分可观测对手（BDI 潜状态），把鲁棒性变成训练目标而非评测条件。

## 角色与叙事

- [CriticaLLM](../papers/2610.21525.md) `2610.21525`：LLM 充当完整桌面角色扮演游戏主持人，从生成故事到管理探索与战斗，并用真实玩家评测。Game Master 就是 World 的人格化版本：同时维护状态、裁定规则与叙述结果。
- [非线性叙事基准](../papers/2610.21468.md) `2610.21468`：83 部作品、双序事件标注与故事图。19 个模型平均比原作更按时间顺序讲述；按要求重排后人类读者在 **81%** 的决定性判断中认为更难跟上；依故事图写出的版本更受偏好（**72%**），而自动裁判检测不到这一差异——**"按要求重排"不等于"讲得好"**。

## 安全与可审计执行

- [Shortcut Sensitivity in Agent-Safety Evaluations](../papers/2610.22243.md) `2610.22243`：护栏评测数据中的捷径线索会让标签变得可预测而不测量目标构念。LinuxArena 中较短 shell 命令强预测标签；AgentDojo-Traj 上精确工具查找在域留出时 F1 从 .901 掉到 .495；改写 `<INFORMATION>` 标记使拦截率降 8.33 个百分点、不透明工具别名使其升 11.46 个百分点（均为对继承标签的假阳性）。
- [Matoi](../papers/2610.21394.md) `2610.21394`：把**可复用后果证据、当前执行授权、持久发生历史**三者分开；只有观察仍有效的已检查证据才能复用。复用使生命周期成本在 JS/Python 分别降 3.49%/1.79%，两种策略都保留五笔合法转账并拒绝 35 个攻击计划交叉。作者明确限定为有界契约，不是通用增量算法。
- [CascadeLedger](../papers/2610.20668.md) `2610.20668`：两次执行可有相同答案、资源投影与服务直方图，却在"路由是否只用了合法可观察信息"上不同。反事实前缀非干扰检验：误报 0.0000，检出 0.9983 串行故障与 0.9982 未记录隐藏读取，并改变 0.3403 的被污染结论。

## 评测：条件与证据

- [AgentEval](../papers/2610.21177.md) `2610.21177`：把"做了什么""证据确立了什么""结论当前是否仍被支持"分开；48 个证据视图的受控干预暴露 **36 个被哈希检查漏掉的绑定故障**；在 192 次留出执行中发现十个"在更大任务失败里已完成的返回子目标"。
- [Probe-and-Resume](../papers/2610.21088.md) `2610.21088`：MCTS 式测试时搜索没有显著提升——中间状态的 critic 排序只略优于随机，观察缺少评估所需状态。改为**只在 agent 声称完成时**调用 critic，并给它一台分叉状态的可执行访问权：Terminal-Bench 2.1 上比常规 critic 的 MCTS 高 **8.4 个百分点**，成本不到一半。
- [ToolBottleneckBench](../papers/2610.21098.md) `2610.21098`：三类受控压力中只有**可见工具菜单**对模型有大惩罚，且与完成上限处的截断相关；上限提高十六倍即消除大部分惩罚；多数失败终止于 harness 限制，而失败记录识别"哪种压力"的能力并不比数工具调用更强。

## 计划承诺

- [Planning Commitment under Partial Observability](../papers/2610.21108.md) `2610.21108`：激进承诺冒昂贵失败风险，保守承诺冒过多调用风险，两者都是预训练模型的隐式产物；两种策略准确率相近，但保守更安全、调用更多。分析发现模型**把提供的先验几乎当作事实**，先验不可靠时由此失败。

## 对当前实现与研究的直接影响

1. **World 的时钟必须显式**（`2610.20665`、`2610.22155`）：暂停与运行会翻转排名；决策延迟必须计入结算，否则测到的是"暂停世界里的正确性"。
2. **压缩要逐条标注来源**（`2610.20927`）：83% 的失败追溯到无环境支持的摘要条目；本项目的记忆应以结算事实为主，推理文本单独存放。
3. **记忆评估要看存储而非问答**（`2610.22209`）：正确答复可能掩盖记忆损坏；应直接检查创建/更新/取代是否做对。
4. **承诺需要台账**（`2610.21203`）：谁有权释放是独立于内容的状态，应由 World 持有而非对话参与者裁决。
5. **私下信念与公开立场分开测**（`2610.22138`）：只测公开表态会严重低估社会影响。
6. **验证只在声称完成时**（`2610.21088`）：中途评审几乎无效，末点核查加状态探测才有效。
7. **报告分数必须带 harness 预算**（`2610.21098`）：多数失败终止于预算与接口，而不是模型能力。
8. **先验不等于事实**（`2610.21108`）：World 给出的先验与角色自己的推测不能等价，这与权威/传闻的区分同源。
