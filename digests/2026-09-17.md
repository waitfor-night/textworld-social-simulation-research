# 2026-09-17 arXiv intake

## 检查范围

检查 arXiv `cs.AI`、`cs.MA`、`cs.CL` 在 9 月 16–17 日公开 recent 页面中的新条目，并用 export API 的 300 条最近更新记录检查已索引论文修订。与 `papers/index.csv` 和 `signals/` 去重后，本轮从大批通用 agent 候选中保留 11 篇直接补足文本社会世界的运行时边界、长程安全、角色连续性、权威状态、恢复和审计证据的工作；未发现已索引论文的新版本。

## 社会运行时与长程安全

- [Agentic Societies Need a Social Harness](../papers/2609.17527.md)：区分个人 harness 与跨主体 social harness，提出预防、运行时验证、事后调查/后果三层控制。
- [Emergence World](../papers/2609.17320.md)：八个十代理世界持续 16 天后注入三类压力事件；检测并不保证遏制，污染信息可写入记忆并在最多 46 小时后影响行动。
- [Collective Loss of Control](../papers/2609.18460.md)：用 mutation—contagion—recovery 描述局部偏差传播；RogueHandoff-20 中危险轨迹注入使作者报告的 executed harm 从 0–5% 上升到 40–95%。论文明确未证明自然自主级联。
- [Who Audits Whom](../papers/2609.18272.md)：将 audit independence 分解为 principal、substrate 和 evidence 三轴，避免同源代理、同工具链和自报日志制造虚假独立性。

## 角色、persona 与持续记忆

- [ANIMASK](../papers/2609.16667.md)：在 3,846 个故事决策点移除 persona 做配对反事实，分离角色约束与 actor model 默认政策。
- [RoleBreak](../papers/2609.16614.md)：在 6,688 个语音话轮中测长程 persona、安全和情感；最强配置也在约十余轮出现首次 persona 或安全失败。
- [Long-Lived Characters](../papers/2609.18935.md)：将本地 NPC 的 recurrent/KV inference state 视为需按时间顺序维护的历史资源，避免过期记忆污染确定性游戏规则。
- [MIRAGE](../papers/2609.19059.md)：固定证据和问题，仅改变 conversation state，表明答案正确不能证明历史来源被真实检索和使用。

## 权威状态、恢复与机制干预

- [ERPBench](../papers/2609.17885.md)：以 live ERP 数据库记录评分，而不是以屏幕操作成功评分；部分 agent 高保存率仍伴随极低正确记录率。
- [Rollback-Induced Reflection](../papers/2609.18304.md)：回滚被错误动作改变的环境状态，同时把结构化反思带入新分支，明确区分世界恢复与经验保留。
- [Interpreting and Steering LLM Agents](../papers/2609.16436.md)：比较 prompt、SAE feature 和 probe direction，尝试把社会模拟中的偏好/能力变成可解释、可干预机制。

## 对系统设计的影响

1. **社会通信需要独立控制层。** RAE 的 personal memory policy 不能代替 SDE/GMS 的身份、消息合法性、传播证据和后果执行。
2. **长期安全必须测传播与延迟效应。** 单轮拒绝率或威胁检测不足以覆盖记忆污染、跨代理传染和数小时后的行动。
3. **persona 必须做因果消融。** 角色表现应与 persona-removed 配对运行比较，否则无法区分角色状态与底模默认行为。
4. **最终答案和 UI 成功都不是权威证据。** 记忆需要 provenance，世界动作需要后端状态验证。
5. **回滚世界与保留知识必须分开。** 每次恢复应产生 branch lineage，并标注从废弃分支带入的 reflection。
6. **审计独立性是系统属性。** auditor 若与被审计者共享 principal、模型 substrate 或不可证明证据，结论应降级。

所有结果均按作者报告记录，不视为独立复现。候选发现使用公开 recent 页面；本次 export API 可用，但仅用于最近 300 条修订交叉检查。`tmp/` 保持未跟踪。
