## 世界、行动与角色：最直接的设计输入

- [ExplorationBench](../papers/2609.30199.md) `2609.30199`：两个与常识相冲突的可执行 Alien Worlds，共 140 个任务；检查 agent 是否通过世界探测学会新规则，且继续探测有时会造成倒退。代码未确认公开。
- [Verifiable Hidden Dynamics Play](../papers/2609.27321.md) `2609.27321`：先求解数学机制，再生成 stateful-tool 世界与评分；作者报告 3,300 个环境，留出与未见机制族验证。是规则/结算/评分同源的实现路径，不是已验证开放社会世界。
- [Agent-Editing World Model](../papers/2609.28416.md) `2609.28416`：重点纠正 agent 的候选推理—行动状态污染，而非凭空预测真实工具响应；作者报告 Action Judge 70.5% 宏 F1、EditAct 六个 benchmark 平均提升 3.2–6.7 点。注意不能把模型对历史的编辑当作 World 事实修改。
- [How Strongly Should Task State Influence an LLM Agent?](../papers/2609.25686.md) `2609.25686`：配对比较历史、checklist、依据执行回执推进的状态指令与强制 gate；gate 有收益，但误判时可能反而伤害小模型/某些任务。
- [Where Does Exactly-Once Live?](../papers/2609.29095.md) `2609.29095`：结算超时与不确定提交下，模型重试无法保证幂等；作者报告 25,930 次 episode，给每次写请求提供幂等键时重复率从 28% 降至 4%。与 `ActionRequest ≠ Outcome` 的边界直接相关。

## 角色与社会模拟的有效性

- [AdvRole](../papers/2609.28609.md) `2609.28609`：Actor/Rewriter 交替学习，自适应改写难角色情境；结果限于角色扮演基准，不代表真实 World 轨迹成功。
- [Emergi-PersonaOS](../papers/2609.27417.md) `2609.27417`：按单个电视剧角色七季 141 集维护版本化三层 persona，研究稳定身份/短期状态/长期变化；正式评分依赖模型评价器，未验证通用多角色世界。
- [PERSONAWEAVER](../papers/2609.26629.md) `2609.26629`：角色背景与道德/交互倾向拆开，使人群回答差异更大；论文提供[公开仓库](https://github.com/mqraitem/PersonaWeaver)，但分布多样性不自动等于后果性角色差异。
- [Behavior is Not Enough](../papers/2609.26481.md) `2609.26481`：public-goods 游戏里测公开表达的经验与规范预期，加消融区分社会学习和网络选择；强调表达出的预期不等于可直接读取模型内部信念。
- [Artificial Societies Benchmark](../papers/2609.30030.md) `2609.30030`：20 个人类数据来源、11 种有效性检查，指出合成问卷复现均值不能替代对差异、结构和条件效应的验证。论文指出分析代码公开，但原始人类数据仍有各自访问条件。
- [Cultural Divergence Preservation](../papers/2609.29928.md) `2609.29928`：跨文化差异可能被压平或夸大，即使单国分布指标看起来不错。
- [Limits of Simulated Societies](../papers/2609.25760.md) `2609.25760`：作者用 12 国 WVS 数据报告后训练中出现的意见分散度压缩；准确率和群体差异须分别报告。

## 邻近但有用

- [When Does Execution Provenance Help Agent Memory Retrieval?](../papers/2609.25913.md) `2609.25913`：将检索单位对齐真实工具事件来源，作者在 2,000 个问题上报告预算内完整证据覆盖提高；图结构的额外收益小于来源对齐收益。先保留观察与请求原始关联，别直接上图检索。
- [Beyond Surface Style / TRACER](../papers/2609.28690.md) `2609.28690`：在客服用户模拟中以真实会话意图变化和轨迹/结果奖励训练，不把表面自然度等同于多轮行为一致性。
