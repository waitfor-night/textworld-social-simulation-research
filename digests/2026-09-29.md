## 世界与状态

- [World Agent: Can Language Models Keep a World Running?](../papers/2609.32692.md) `2609.32692`：把世界模型评测从"交付"后移到"持续运行"，要求把叙事事件落到显式世界状态的正确转移，并由后果约束后续演化。这与本项目"World 是权威状态来源"的定位直接对应，也说明单步状态正确不足以证明因果事件流正确。
- [The GUI Is Not the State](../papers/2609.32679.md) `2609.32679`：指出 state aliasing —— 相同可观察条件可对应不同有效未来，并给出预测状态恢复接口。
- [Positions Are Not Facts](../papers/2609.33759.md) `2609.33759`：事实更新时遮蔽旧记录会让 8 个模型中的 6 个丢失单位或无法停止；多跳更新下重建状态使历史准确率下降 20–41 个百分点。"保留被替换值"因此不只是设计偏好，而是可测量的正确性要求。

## 角色、persona 与选择性控制

- [Persona Following Is Not Selective Control](../papers/2609.35036.md) `2609.35036`：改变一个目标属性会牵连未指定属性（把用户描述得更偏好风险后，连颜色选择都变），八个模型全部存在。这为"same World + different Role → different Trajectory"的对照提出必须预注册的控制变量。
- [How Far Do Persona Effects Generalize?](../papers/2609.32758.md) `2609.32758`：persona 效应"可预测但不可迁移"——同一模型内可预测，跨模型借用增益多数方向不如共享缩放，改写措辞后重拟合显著优于复用。
- [PersMem](../papers/2609.34372.md) `2609.34372`：把人格映射为记忆管线的操作参数（情感评估、保留、检索），使记忆处理本身成为角色差异来源。
- [PersonaManifold](../papers/2609.34571.md) `2609.34571`：persona 表征可能位于弯曲流形上，欧氏加减与线性插值系统性失效——为"persona 维度不正交"提供几何解释。
- [Proactive Dialogue Policy Optimization via Cognitive-State Transition](../papers/2609.34948.md) `2609.34948`：用户模拟器需要显式的认知与情感状态转移，否则多轮反馈无法区分"用户变了"与"模拟器波动"。

## 接口、授权与效果边界

- [Action-Space Shaping](../papers/2609.34971.md) `2609.34971`：同一个可执行动作用九种等价 schema 暴露，任务与可达状态不变，成功率却随写法变化——接口是行动空间的一种表示，不是行动空间本身。
- [When Valid Tool Calls Change Meaning](../papers/2609.35088.md) `2609.35088`：schema 合法的调用在延迟批准、重连或版本变化后可能绑定到不同实现并产生不同安全效果（schema-epoch drift）。
- [Authorization Closure Graph](../papers/2609.32428.md) `2609.32428`：指令局部变更时只失效受影响的授权并计算最小修复；代码已公开。
- [When Consent Outlives Context](../papers/2609.33910.md) `2609.33910`：长寿命 agent 中残留授权可被后续对抗执行复用，在 508 个 AgentDojo 用例上提高 prompt injection 与 context rebinding 的成功率。
- [Trust the Brand, Lose Control](../papers/2609.32635.md) `2609.32635`：编排者依据子 agent 展示的身份分配权限，身份可被伪造。
- [Formation-Consistent Dispatch](../papers/2609.35088.md) 与 [EffectMatch](../papers/2609.31301.md) 一并支持：Request ≠ Outcome，且"被批准"≠"只产生被批准的效果"。

## 记忆的准入、时效与顺序

- [TRACE: Governing Memory Validity](../papers/2609.33517.md) `2609.33517`：一条记忆可以正确检索、相关且忠实，却已经**无权**用于行动；提出 temporal memory admission 与受限 Return View。
- [The Epistemics of Agent Memory](../papers/2609.33013.md) `2609.33013`：把评测重点从"记得多少"移到"巩固决定是否可信"，并诚实报告一个未达门槛的近似（0.691 vs 0.70）与两个失败模式（退化遗忘、lambda-prevalence coupling）。
- [RoutePrism](../papers/2609.34160.md) `2609.34160`：同一批记录换个处理顺序就会丢弃不同证据；恢复被挤掉的那一条可回升 60+ 个百分点，替换为等长非支撑记录则不会。
- [When Does Selection Replace Extraction?](../papers/2609.34227.md) `2609.34227`：预注册研究显示紧预算下选原始轮次不劣于抽取式记忆，写入成本低 3,061 倍；但预算宽松时抽取式更准——结论随预算反转。
- [COUNTERMEM](../papers/2609.31874.md) `2609.31874`：失败后的"如果换个动作会怎样"必须由可执行世界模型核验后才成为记忆。
- [From Attack Success to Attack Severity](../papers/2609.34132.md) `2609.34132`：记忆攻击应报告下游后果严重程度，而非仅报告是否成功。
- [How Far Do Persona Effects Generalize?](../papers/2609.32758.md)、[Graded Belief Stability](../papers/2609.34158.md) `2609.34158`（83.3% 的模型—领域组合中低稳定度信念在挑战下移动更大）分别从迁移性与体系支撑度定义"可靠"。

## 共享世界、协作与治理

- [Agentsensus](../papers/2609.32297.md) `2609.32297`：同一事件在多名见证者之间合并为一条共有记录；写入条目比基线少 22–44%，且是唯一同时具备共享性（14–28% 由多人持有）与链接性（94–99%）的设计。
- [MASTraceBench](../papers/2609.34496.md) `2609.34496`：只看最终答案会掩盖协作是否真有贡献——最终答案很少超过最强初始提案。
- [CoMemBench](../papers/2609.32192.md) `2609.32192`：把"任务条件下的信息边界"作为评测对象，共享与隔离都要满足。
- [Relic](../papers/2609.32965.md) `2609.32965`：把协作失败固化为组织持有、可执行、可修订的协议，完整契约交付率 14.06% → 19.76%。
- [DGF-Bench](../papers/2609.34913.md) `2609.34913`：用配对干净副本把"注入造成的成功"与"结果碰巧变坏"分开。
- [ORBIT](../papers/2609.33102.md) `2609.33102`：多智能体安全评测需要联合变化攻击、防御与拓扑，否则无法标准化比较。
- [LLMs Trust Their Own](../papers/2609.33495.md) `2609.33495`：服从程度取决于对方身份的内外群体属性，且模型不像人类那样被单个盟友打破多数一致。

## 审计、记录与负结果

- [Hearsay](../papers/2609.32495.md) `2609.32495`：十六个已部署框架都没有写出可独立核验的运行记录；审阅者能指出故障（74–91%）却难以证明过程，引用中不到十分之一落在非 harness 撰写的内容上。
- [Compact Documentation for Coding Agents](../papers/2609.31587.md) `2609.31587`：诚实的负结果——文档完整度决定能否重建代码，但源码可用时更好的文档并不改善真实问题解决，作者附上了阳性对照。
- [Compress What You See, Not What You Say](../papers/2609.31430.md) `2609.31430`：压缩应限于可再获取的观察，角色自身表达与最近交互保持原文。
- [FlowState](../papers/2609.34565.md) `2609.34565`：把执行状态本身作为可保留、可回访的记忆，而非在全量与有损压缩之间二选一。
- [Learning What to Recall](../papers/2609.34677.md) `2609.34677`：以"对当前预测是否有用"为学习信号决定召回，替代近期性/相似度启发式。
- [Memory as Middleware](../papers/2609.32091.md) `2609.32091`、[DAAF](../papers/2609.32498.md) `2609.32498`、[CORTEX](../papers/2609.33260.md) `2609.33260`：分别为记忆中间件、可编辑系统资产的失败归因、带来源与成立条件的经验复用层提出框架；三者摘要层均未给出对照实验数值，本笔记按低证据强度记录。

## 对当前实现与研究的直接影响

1. 世界评测单元应是"持续运行下的状态一致性"，而不是单次请求是否返回合理观察（2609.32692、2609.32679）。
2. 事实更新必须保留被替换值所携带的结构；遮蔽会制造看似完整实则缺项的答案（2609.33759）。
3. 角色差异实验需预注册允许变化的属性，并检查未指定属性是否被牵连（2609.35036）；persona 效应不可默认跨模型迁移（2609.32758）。
4. 记忆需要三段式区分：能否写入、当前值是什么、现在还能否据此行动（2609.30813、2609.25054、2609.33517）。
5. 记忆评测要报告构建顺序敏感性与巩固失败模式，而非只报最终准确率（2609.34160、2609.33013）。
6. 紧预算下优先保留原始事件；抽取式摘要的收益随预算变化会反转（2609.34227），与当前 `recentMemory` 的取向一致。
7. 授权需绑定语境与有效期，并在效果边界复核；接口等价性变化本身会改变可测行为（2609.33910、2609.32428、2609.34971）。
8. 轨迹由 agent 自己写入时不构成证据（2609.32495）。

所有数值均按作者报告记录，不视为独立复现。预先存在的 `tmp/` 保持未跟踪。
