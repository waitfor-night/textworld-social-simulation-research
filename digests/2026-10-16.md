## 世界模型：评测分层与选择性建模

- [CivWorldBench](../papers/2610.16450.md) `2610.16450`：**本轮最重要的一篇**。在多智能体策略游戏引擎上记录内部状态与受控观察，用 475 个世界的 1,900 个决策点分三层评测：关联预测、信念推断、干预预测。11 个前沿模型中，**强关联预测不能一致地延伸到信念推断与干预预测**，方向预测有信息而**效应量校准很差**；过程验证发现最终答案评测漏掉的错误。作者明确将隐藏状态推断、中间状态预测与效应校准列为世界模型训练的重点。
- [DGS-WM](../papers/2610.19642.md) `2610.19642`：把完整观察一律当作世界建模目标会忽略决策相关性，改为只对“支持后续策略响应”的观察单元做监督，并按预测置信度自适应调节强度。
- [PAWA](../papers/2610.20240.md) `2610.20240`：多人世界模型必须预测**视野之外**的共享环境变化；用同步点视角 + 世界稳定化全景视频（支持 64 名以上玩家）训练双塔模型，并引入二次相位玩家编码。

## 社会模拟：尾部角色、产物核验与先验注入

- [HICO-Bench](../papers/2610.20195.md) `2610.20195`：两个持有私人信息的 agent 谈完后**各自独立记录计划**，程序检查两份记录一致且满足双方私人条件，LLM 裁判只检查对话是否支持该记录。**36% 被评委高度评价为完成目标的对话未通过 Verified Success**；PaCPO 把 Qwen3-8B 从 20.4% 提到 28.3%。这是"Request ≠ Outcome"在对话层的直接对应。
- [EXAM](../papers/2610.19863.md) `2610.19863`：社会模拟长期关注代表性人格，但**持续存在的尾部行动者**会不成比例地塑造集体动态；在选举、金融危机、疫情舆论、重复囚徒困境四个场景中，小规模持续尾部群体产生与主干模型和场景相关的集体偏移。
- [Social Priors](../papers/2610.16946.md) `2610.16946`：同一批 1,625 个真实使用场景，只在"用户动机"归因上不同的四份语料，足以改变模型对**人**的信任与合作行为——反社会语料下，模型几乎不给人资源却把大部分给同记录的随机设备；**单个反社会 agent 就让每一组本来可持续的 agent 耗尽公共资源**。信念偏移在反社会文档仅占 1% 训练词元时即出现。
- [Event Memory and Narrative Dynamics](../papers/2610.16971.md) `2610.16971`：受海马体情景记忆模型启发，用显式边界规则与特征模式把自传体叙事构造成事件状态（5 名受访者 → 256 个事件状态），并用后继表示建模跨步结构。
- [Narrative Lookahead](../papers/2610.18121.md) `2610.18121`：以事件而非 token 度量叙事前瞻——未来事件类型在**至少四个后续事件**上可解码，但只有下一个事件的预测显著优于纯文本预测器。

## 角色与人格：知识诅咒、社会轨迹与人格鲁棒性

- [The Curse of Knowledge in Role-Playing LMs](../papers/2610.17327.md) `2610.17327`：用反事实孪生（只改隐藏事实）测量泄露：角色使用**听不到、听不懂**内容的比例分别高出基线 **67 与 72 个百分点**，泄露也延伸到隐藏动作与私信；仅改变场景布局或角色描述就让原本合规的模型从 <10pp 跳到 >60pp；**只给模型角色可观察的内容即可阻止泄露**。这是本项目 World→Observation 硬边界的最强外部证据。
- [Agent Sociodrama](../papers/2610.15788.md) `2610.15788`：每轮由统一外部裁判更新**情绪状态与有向非对称关系**，并用轨迹引导的人格重铸（TPR）诊断群体动态失败后重跑任务，最高提升 83.3 个百分点。
- [TIPER](../papers/2610.16155.md) `2610.16155`：标准用户模拟器过于配合会高估鲁棒性，但对抗搜索又容易把任务弄失效；TIPER 在**任务完整性约束**下演化持续存在的用户人格，在 28 个 agent—领域对上中位数降低 22.9 个百分点。
- [PersEvalBench](../papers/2610.19314.md) `2610.19314`：LLM 裁判对个性化错误识别有限，且常**颠倒错误方向**（把"该用没用"判成"不该用却用了"）；高亮相关历史几乎无帮助，说明难点在于判断信息应扮演什么角色。

## 记忆：事件聚合、回声、删除与退休

- [TallyMem](../papers/2610.19474.md) `2610.19474`：关于历史的问题常需**聚合事件**，而检索解决不了聚合；在来源可寻址的阅读视图上加可复用事件台账与确定性执行，Qwen3-32B 精确匹配 35.2% → 49.0%。
- [Memory Echo](../papers/2610.17763.md) `2610.17763`：同一条历史主张经重复检索与回写会占据多个检索位置，在无新证据时影响回答。FPA 按来源族去重、以已验证更正约束老记录、用权威证据约束回答：准确率 0.825 → 0.920（DeepSeek V4 Flash），决策污染效应 0.106 → 0.030。这是 LQET 谱系更新的**检索端**对应物。
- [Bemula](../papers/2610.18052.md) `2610.18052`：用户要求删除记忆时，**没有任何系统端到端通过超过 1.5% 的遗忘请求**——要么删不干净（简单攻击即可提取），要么删得远超请求范围。记忆删除仍是开放问题。
- [Suggested Is Not Superseded](../papers/2610.15710.md) `2610.15710`：基准的二值标签无法区分"依据既成变化"与"依据暗示"；三类判定（SUPERSEDED / NEEDS-CONFIRMATION / COMPATIBLE）下，二值闸门对仅有暗示的变更退休 39.2%，三路判定降到 15.5% 但付出 15.3 个点检测代价。**直接建议：二值判定不应接到删除动作上**。
- [MemForm](../papers/2610.14431.md) `2610.14431`：把记忆投毒按**形成接口**（内容、证据、范围、选择、路径）分类；关键是**同样的保留体验、不同巩固顺序也能改变行为**——写入策略本身是可评测对象。

## 信念与心智理论

- [The belief-action gap](../papers/2610.17444.md) `2610.17444`：状态与价值信息在内部表征上**比在行为中体现得更可靠**，部分失败发生在"把已有信息翻译成行动"这一步；决策在某个**承诺点**附近变得明确，信念不确定性同时下降；移植的推理前缀可以强制动作，而激活编辑控制力有限。
- [Beyond Belief Nesting](../papers/2610.17777.md) `2610.17777`：现有高阶 ToM 基准普遍存在**阶数虚高**；直接提示下准确率从一阶 73.5% 降到四阶 20.0%；HopTrace 把每次交互编码为视角记录后确定性解析，四/五阶分别提升 22.0 与 38.5 个百分点，token 用量少 20–39 倍。
- [Smart Alone, Blind Together](../papers/2610.19051.md) `2610.19051`：**准确率不是心智理论模块的正确证书**——错误相关性有符号：从 GPT-5.4-mini 到 Claude Opus 5.5，对队友的错误率从 32% 降到 11%，但三人同时误读的概率只从 16% 降到 9%（独立时本应是 3.4% → 0.15%）。

## 安全、归因与长程执行

- [BLADE](../papers/2610.18780.md) `2610.18780`：失败归因不止于追踪信息来自哪里，而要**审计它被如何使用**；在 1,228 个失败运行上步骤准确率优于 All-at-once 2.2–11.1 个百分点。
- [RetryBench](../papers/2610.15884.md) `2610.15884`：**错误的重试许可**须与恢复结果分开报告——被改动的密钥诱发无依据重试（Terra 55/80、Luna 60/80），而成功的受保护恢复并不意味着能可靠拒绝无依据重试。
- [RECONS](../papers/2610.16039.md) `2610.16039`：多智能体隐私泄露是拓扑问题——对拓扑引入的接收方披露从 0% 升到 52.2% 而表面泄露几乎持平；接收方条件化消毒把残余披露从 96.7% 降到 29.25%，同时保留 94.1% 合法披露（全面涂黑只剩 20.5%）。
- [DeLoop](../papers/2610.19376.md) `2610.19376`：**历史压缩会诱发动作循环**（重复工具调用、相同观察）；用循环动作与其后第一个非循环动作做偏好对，含循环任务比例 57.3% → 6.1%，Qwen3-32B 成功率 37.7% → 44.8%。
- [Cowork-Gym](../papers/2610.17670.md) `2610.17670`：以"构建—执行—修正"循环合成 64.9K 个协作环境（14 个应用场景），配有状态用户模拟器通过对话与**直接编辑共享工作区**回应 agent；6 个基准上 9B/27B/35B 分别 +8.7/+6.4/+4.1 个点。

## 对当前实现与研究的直接影响

1. **世界模型能力要分层评测**（`2610.16450`）：关联预测、信念推断、干预预测是三个不同的能力，强关联预测不能外推到后两者；本项目若要做角色世界模型，应按此分层设指标。
2. **观察边界必须是硬边界**（`2610.17327`）：只提供角色可观察内容即可阻止知识诅咒；"能陈述感知"与"实际使用感知"是两件事，需反事实孪生来测量。
3. **判定应落在产物上而非裁判上**（`2610.20195`）：独立记录的计划加程序核验，比 LLM 裁判评分更能发现"对话成功但结果失败"。
4. **记忆写入顺序本身是变量**（`2610.14431`）：同样保留的体验、不同巩固顺序会产生不同行为。
5. **二值删除应改为三值路由**（`2610.15710`）：建议改成 SUPERSEDED / NEEDS-CONFIRMATION / COMPATIBLE，把"有暗示的变化"路由到待定证据。
6. **压缩记忆要监控循环**（`2610.19376`）：压缩历史会诱发重复动作，需把重复动作率作为压缩的伴生指标。
7. **信念与行动之间的翻译是独立失败面**（`2610.17444`）：记录"信息缺失"与"信息未被用于行动"要分开。

所有数值均按作者报告记录，不视为独立复现。预先存在的 `tmp/` 保持未跟踪。
