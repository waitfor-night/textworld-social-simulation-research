### 状态、信念与信息边界

- [Classic AI Scaffolding for LLM Social Agents](../papers/2609.01167.md) ([arXiv 记录](https://arxiv.org/abs/2609.01167)) — 提交于 2026-09-01；`SIM/core`；置信度 `medium`。EpisodeSim 在 World Master 下将角色、义务、物质状态、时序、承诺和收尾变为持久控制状态。在一项由作者裁定的小型试验中，完整脚手架报告的主要场景失败为 0/6，而 minimal 与 grounded 变体均为 6/6；该结果是设计诊断，而非通用基准测试。
- [Towards a Belief-Based World Model for LLM Agents](../papers/2609.00455.md) ([arXiv 记录](https://arxiv.org/abs/2609.00455)) — 提交于 2026-08-31；`TWM/core`；置信度 `medium`。在部分可观测的 ALFWorld 和 ScienceWorld 任务中，将可查询的信念层与动作模拟分离，并提供公开复现代码。论文的性能和消融数字是作者报告，手工设计的状态模型仍具有领域特定性。
- [ArcticSwarm: Deferring Early Consensus in Long-Horizon Multi-Agent Research](../papers/2609.01870.md) ([arXiv 记录](https://arxiv.org/abs/2609.01870)) — 提交于 2026-09-01；`MAS/core`；置信度 `medium`。研究在 BrowseComp-Plus 和 live BrowseComp 上测试了隔离的搜索上下文、共享公告板以及分阶段承诺/审查。报告的增益支持把延迟共识视为消融假设，但不同供应商之间的比较以及缺少关联实现限制了重放。

### 社会互动、文化与群体有效性

- [GlossoGen: Emergent Language in Complex Multi-Agent LLM Interactions](../papers/2609.01491.md) ([arXiv 记录](https://arxiv.org/abs/2609.01491)) — 提交于 2026-09-01；`MAS/core`；置信度 `medium`。SaveVeyru 平台提供部分观测、通信渠道、重放/fork/swap 干预和传播测试。作者报告称，智能体在压力和事后复盘权限下形成了有成效的约定，其中包括人类无法解读的代码；证据来自一个规模较小的虚构合作场景，没有对抗性群体或人类基线。
- [Benchmarking large language model agent societies against human behavioural distributions (SILICA)](../papers/2608.28182.md) ([arXiv 记录](https://arxiv.org/abs/2608.28182)) — 提交于 2026-08-28；`SIM/core`；置信度 `medium`。五个以人类为锚点的社会/经济环境、带种子的开放权重运行、表示/设计扰动以及收益分歧控制，将首轮拟合与终态和交互有效性区分开来。论文链接了代码、转录文本、可复现实验发布包和 OSF 存档，但锚点与探索性单元仍需独立审计。

### 记忆与长程控制

- [CHIME: Credit-Aware Hierarchical Memory Evolution for Long-Horizon Agentic Planning](../papers/2609.02074.md) ([arXiv 记录](https://arxiv.org/abs/2609.02074)) — 提交于 2026-09-02；`AGT/core`；置信度 `medium`。该方法将规划记忆与执行记忆分开，并在写入前归因结果。在四个列出的长程基准测试中，作者报告了平均增益、一次比较中保留记忆从 3,585 条减少到 129 条，以及最高 97.9% 的归因一致性；承诺发布的 CHIME 实现尚未被独立找到。
- [Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems](../papers/2609.00237.md) ([arXiv 记录](https://arxiv.org/abs/2609.00237)) — 提交于 2026-08-31；`MAS/adjacent`；置信度 `medium`。学习到的写入、检索、角色/骨干选择和停止门控提升了报告中的推理/代码分数并降低成本。我们检查了关联仓库，但在观察时它只公开了许可证；而且封闭领域评测并未证明其能安全保留社会事实或规范。
- [Invalidation Contracts for Cross-Episode Agent Memory](../papers/2609.00243.md) ([arXiv 记录](https://arxiv.org/abs/2609.00243)) — 提交于 2026-08-31；`AGT/adjacent`；置信度 `medium`。带版本的逐行失效机制在 9,432 个 API 恢复回合中，将记忆有效性与规划器遵从性分开。配套的服务器/客户端工件使协议可检查，但许可和来源有所不同，合成 API 的范围也使其尚未覆盖人际漂移。

### 评测与证据完整性

- [trajectory-judge: What Outcome-Only LLM Judges Miss on Agent Trajectories](../papers/2609.00038.md) ([arXiv 记录](https://arxiv.org/abs/2609.00038)) — 提交于 2026-08-29；`EVAL/core`；置信度 `medium`。确定性的支持服务台故障注入器标记静默与显性过程失败，并在 400 条轨迹上评测五个评判器。只看结果的评判报告了 45% 的静默故障召回率和 33% 的干净样本误报率；步骤感知的评判器以更高成本改善了静默召回，但狭窄的脚本化领域和单故障设计限制了迁移。
- [ClaimReceipt: Verifying Evidence Sufficiency and Coverage in Agent Evaluations](../papers/2609.01992.md) ([arXiv 记录](https://arxiv.org/abs/2609.01992)) — 提交于 2026-09-02；`EVAL/adjacent`；置信度 `medium`。以主张为中心的收据和显式的 `INCONCLUSIVE` 状态，用于测试一项汇总评测是否由完整证据集支持。作者报告了 1,392 条历史记录和 30 项前瞻性分配，并进行了注入故障与覆盖检查，但以交易为中心的协议和规范可读性问题仍需要独立实现。

## 反复出现的方法与环境

1. **文本之外的权威性。** EpisodeSim 的 World Master、BB-WM 的信念投影、ArcticSwarm 的可见性边界，以及 Invalidation Contracts 的版本范围，都把隐藏的控制层显式化。社会情节应将权威状态、各智能体的信念、允许使用的证据和失效条件，与生成的对话分开并显式提供。
2. **受生命周期管理的记忆。** CHIME 处理写入前的归因；Gated-Memory 处理写入/检索/停止决策；Invalidation Contracts 处理过时问题。合在一起，它们意味着记忆记录应包含溯源、范围、效用或归因、保留决策和失效规则，而不是一份未区分的转录文本。
3. **可进行干预的交互底座。** GlossoGen 的重放/fork/swap 钩子、SILICA 的表示与收益扰动，以及 trajectory-judge 的故障注入器，将表面上像社会行为的现象变成可检验的反事实。固定种子、原始事件日志和可见性轨迹应成为默认输出。
4. **有界情节与分阶段承诺。** EpisodeSim 和 ArcticSwarm 都把时序与承诺边界视为因果变量。这对图谱计划中的文本世界测试台很有用，因为其中可以直接测量过早共识、延迟义务和收尾失败。

## 正在变得普遍的评测模式

- **过程与结果：** trajectory-judge 将静默的、结果仍然成功的故障与显性失败分开；ClaimReceipt 将有效、无效和证据不足的主张分开。社会评测应同时报告发生了什么，以及路径和证据是否有效。
- **扰动与污染控制：** SILICA 改变呈现方式、顺序、标签和激励，以测试结果能否经受装置变化，还是只是从先前结果中被记起。GlossoGen 改变压力、事后复盘权限和智能体交换。这些做法强于一次性的提示词加分数运行。
- **群体与分布检查：** SILICA 将轨迹和终态与人类分布比较，而不是评判一段看似合理的对话。GlossoGen 分别衡量涌现、传播和可理解性。个体角色一致性、群体协调和群体有效性应保持为不同指标。
- **成本与覆盖核算：** CHIME 和 Gated-Memory 报告记忆或推理成本；ClaimReceipt 报告证据覆盖和验证器开销；trajectory-judge 报告评判的墙钟成本。没有分母、仪器记录或成本的单一主指标，对本图谱而言是不够的。

## 分歧、薄弱主张与缺失基线

- **连贯性不等于真实感。** EpisodeSim 的小型定性试验和 GlossoGen 的成功约定表明，显式脚手架可以稳定互动，但两者都没有证明具有人类式的社会动态。SILICA 较弱的终态一致性则是对流畅演示的有益制衡。
- **记忆增益可能以遗漏为代价。** 具备归因意识和门控的保留机制可以减少噪声与成本，但丢弃低频关系、安全信息或规范事实，可能比保留冗余上下文更有害。当前提升的论文都没有在变化中的社会世界里完整检验这一点。
- **工件状况不一。** BB-WM、GlossoGen、SILICA、trajectory-judge 和失效客户端提供了可检查材料；CHIME 承诺发布的实现，以及 Gated-Memory 关联但目前稀疏的仓库，还不能等同于可复现实验包。因此应据此调整对主张的权重。
- **可比性脆弱。** 多篇论文比较了不同供应商、骨干模型、提示词或基准切片。作者报告的改进不被视为独立复现，而且目前没有提升条目为开放式社会情节提供跨文化的人类锚点。
