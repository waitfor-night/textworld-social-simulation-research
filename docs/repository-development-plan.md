# 仓库发展总体方案：从文献雷达走向个人研究体系

## 1. 目标与边界

本仓库不追求成为覆盖所有 language agent 与 social simulation 论文的公共目录。它应服务于一条明确主线：

> 从可执行文本环境出发，研究身份受限的语言智能体如何观察、记忆、行动和交互；局部行为如何经网络与制度形成宏观事件；宏观事件又如何改变权威世界状态并反馈给不同参与者，最终沉淀为一个可重放、可干预、可评估的 text world model。

因此，仓库未来同时承担四种职责：

1. **历史谱系**：解释当前设计从哪些环境、智能体架构和社会模拟工作演化而来；
2. **证据地图**：区分论文事实、作者声称、复现实证、早期信号与个人判断；
3. **设计决策记录**：把文献结论转成系统边界、接口、实验和否决条件；
4. **项目路线图**：持续回答“下一步该读什么、复现什么、实现什么，以及为什么”。

不做的事：不机械导入综述全部参考文献，不以论文数量作为进度，不把大规模、多智能体或流畅叙事本身视为有效性证据。

## 2. 六个审查视角的综合结论

本次按六个并行视角审查现有仓库；当前环境没有独立 subagent 工具，以下是同一轮中按角色分工完成的综合。

### 2.1 研究史与谱系

现有 `papers/index.csv` 共 42 篇，2024 年以前仅 1 篇，绝大多数集中在 2026 年 8–9 月。仓库擅长捕捉前沿信号，但无法解释这些工作为何出现、继承了什么、解决了哪些旧问题。

缺失的历史链条至少包括：

- **文本环境**：TextWorld / Jericho → LIGHT / ALFWorld → 近期可执行终端、GUI 与混合环境；
- **语言智能体架构**：ReAct → 记忆、反思、技能库、认知架构 → 长程与跨情节智能体；
- **生成式社会智能体**：Generative Agents → SOTOPIA / Concordia / AgentVerse → 大规模社会模拟与人类分布校准；
- **角色与人格**：persona prompting → role-playing language agents → 身份、记忆、社会关系和个性化评测。

结论：先补“桥梁论文”，再补细枝末节；每篇历史论文都必须解释它与当前设计的因果关系。

### 2.2 综述与引文审计

适合作为引文入口的综述/框架论文：

- [A Survey on Large Language Model based Autonomous Agents](https://arxiv.org/abs/2308.11432)：规划、记忆、工具与环境的总入口；
- [Cognitive Architectures for Language Agents](https://arxiv.org/abs/2309.02427)：把语言智能体映射到感知、记忆、决策和行动循环；
- [From Persona to Personalization](https://arxiv.org/abs/2404.18231)：角色扮演智能体的角色构建、行为与评测入口；
- [From Individual to Society](https://arxiv.org/abs/2412.03563)：LLM 社会模拟的个体、交互、环境与社会层级入口；
- [Integrating LLM in Agent-Based Social Simulation](https://arxiv.org/abs/2507.19364)：现有索引中连接传统 ABM、混合架构、验证与校准的入口。

引文回溯不应按“被引次数”直接收录，而应经过三问：它是否定义了后来沿用的环境/协议？是否提供了可执行 artifact 或基准？是否直接支撑 `design-synthesis.md` 中的部件或评估主张？

### 2.3 文本环境与 agent 架构

仓库当前把 2026 年的记忆、规划和评测拆得很细，却缺少这些机制的共同实验底座。建议优先建立以下桥梁：

- TextWorld、Jericho：文本动作空间、状态和通用交互协议；
- LIGHT：语言、行动、角色身份和社会世界的结合；
- ALFWorld：文本环境与具身状态对齐；
- ReAct：推理—行动—观察循环；
- Generative Agents：记忆流、反思和计划如何进入持续社会世界；
- Voyager：技能库、自动课程和环境反馈如何支持开放式长期学习。

这些论文不是“背景装饰”，而是未来比较新工作时的基线坐标。

### 2.4 社会模拟、角色与制度

当前索引对 2026 年的社会机制覆盖较密，但基础参照不足。最应补的对象是：

- Generative Agents：持续生活世界与涌现社会行为；
- SOTOPIA：有目标、角色与关系约束的社会互动评测；
- Concordia：基于 Game Master、规则和叙事组件的生成式 ABM；
- AgentVerse / CAMEL：多智能体协作、通信和角色分工；
- GenSim、SocioVerse、YuLan-OneSim：2024–2025 年由小规模演示走向通用平台、人口规模与真实数据锚定的过渡；
- Social Science Meets LLMs：对可靠性、偏差和外推边界的反证入口。

社会模拟条目必须标明它模拟的是“模型行为、制度内行为，还是真实人类分布”，避免把三者混写。

### 2.5 评测、有效性与复现

现有仓库已经重视轨迹、可重放性与人类锚点，但缺少统一的证据等级。建议每篇核心论文以后都回答：

1. 环境状态是否权威且可检查？
2. 动作是否真正执行，还是只由文本/LLM judge 判定？
3. 结论是单次演示、模型内稳定、跨模型稳定，还是与人类数据一致？
4. 是否公开代码、数据、prompt、模型版本、种子和完整轨迹？
5. 干预是否能改变预期机制，而不只是最终输出？

将证据分为四级：`E0 概念/演示`、`E1 受控实验`、`E2 可复现 artifact`、`E3 人类或真实系统锚定`。该等级适合写入论文模板和看板，但应在第二阶段实施，避免现在同时改动全部旧条目。

### 2.6 仓库产品与工作流

当前目录结构已足够，不需要新数据库或复杂知识图谱。真正缺少的是“历史回填队列”和“论文到设计决策的链接”。建议保留现有 Markdown + CSV：

- `papers/` 保存可长期引用的结构化证据；
- `signals/` 只保存尚未成熟、版本变化或公开讨论；
- `digests/` 记录每轮变化，不承担长期综述；
- `docs/design-synthesis.md` 保存当前设计；
- 本文保存仓库发展与回填路线。

## 3. 分时期扩充计划

### 阶段 A：基础环境与语言行动（2018–2021）

目标：补齐“文本世界如何成为可执行实验环境”。

首批候选：

| 优先级 | 论文 | 作用 |
| --- | --- | --- |
| P0 | TextWorld: A Learning Environment for Text-based Games | 环境生成、状态、动作与交互协议基础 |
| P0 | Jericho: A Learning Environment for Knowledge-Based Language Agents | 互动小说基准、世界状态与动作有效性 |
| P0 | Learning to Speak and Act in a Fantasy Text Adventure Game (LIGHT) | 将角色、语言和动作放入社会化文本世界 |
| P0 | ALFWorld | 文本观察/动作与具身环境状态对齐 |

完成标准：至少形成一篇“环境谱系”综合说明，明确结构化状态、自然语言接口、部分可观察性和可重放性如何演化。

### 阶段 B：LLM 智能体架构与持续行动（2022–2023）

目标：补齐“语言模型如何成为有记忆、计划和工具循环的智能体”。

首批候选：

| 优先级 | 论文 | 作用 |
| --- | --- | --- |
| P0 | ReAct | 推理—行动—观察闭环 |
| P0 | Generative Agents | 记忆、反思、计划与社会世界 |
| P1 | CAMEL | 角色提示与多智能体通信 |
| P1 | AgentVerse | 多智能体协作与涌现行为框架 |
| P1 | Voyager | 技能库、自动课程与长程环境学习 |
| P0 | Cognitive Architectures for Language Agents | 连接认知概念与 agent 模块的分析框架 |
| P1 | A Survey on LLM-based Autonomous Agents | 作为历史引文入口，不作为效果证据 |

完成标准：当前 2026 年记忆/规划条目都能回链到至少一个早期架构基线，并指出“新增机制究竟超越了什么”。

### 阶段 C：社会交互、角色与生成式 ABM（2023–2024）

目标：补齐“小镇演示如何过渡到有协议、可评测的社会模拟”。

首批候选：

| 优先级 | 论文 | 作用 |
| --- | --- | --- |
| P0 | SOTOPIA | 社会目标、关系、互动协议与评测 |
| P0 | Concordia | Game Master、规则、叙事和 ABM 组合 |
| P0 | From Persona to Personalization | 角色构建与角色评测综述入口 |
| P0 | From Individual to Society | LLM 社会模拟综述入口 |
| P1 | GenSim | 通用社会模拟平台化过渡 |
| P0 | Social Science Meets LLMs | 可靠性和有效性反证 |

完成标准：为 `design-synthesis.md` 的 RAE、SDE、WSE、GMS 四部件分别找到支持与反例；明确生成式叙事和权威状态的边界不是单篇论文已经解决的事实，而是本项目的设计选择。

### 阶段 D：规模、校准与世界模型化（2025–2026）

目标：把现有高密度前沿条目组织成问题链，而不是按日期堆叠。

建议专题：

1. **规模与效率**：AgentSociety、SocioVerse、YuLan-OneSim 与近期规模极限工作；
2. **人类有效性**：DEBATE、SILICA、persona 预测、社会影响与可靠性研究；
3. **状态与世界模型**：ALFWorld → belief-based world models → text world models；
4. **长期记忆**：Generative Agents → RuleMem / CHIME / invalidation / portability；
5. **过程评测与安全**：轨迹 judge、接口删失、权限连续性与可重放观察者。

完成标准：每个专题产出一个对照表，至少包含环境、观察、动作、状态权威、时间尺度、群体尺度、评测、人类锚点和 artifact 状态。

## 4. 收录优先级与数量预算

首轮只新增 **12–16 篇** 历史桥梁论文，防止从“只看新论文”滑向“无差别旧论文堆积”。建议分配：

- 2018–2021：4 篇；
- 2022–2023：5–6 篇；
- 2024：4–5 篇；
- 2025 的平台/有效性桥梁：2–3 篇。

优先级规则：

- **P0**：直接定义环境、架构、社会协议、有效性基准或当前设计关键边界；
- **P1**：被多个综述共同引用，且补足一个缺失机制；
- **P2**：只作背景或同类实现，先保留在候选表，不建立论文笔记。

新增论文前必须检查规范 ID、版本、代码/数据链接及现有 `signals/`；综述中的数字和分类只能作为线索，最终字段以论文原始页面为准。

## 6. 结构与流程的小幅改进

在完成前两批历史回填后，再做以下最小调整：

1. 在 `papers/index.csv` 增加 `evidence_level` 和 `lineage` 两列；旧条目可暂空，不立即全量迁移；
2. 在论文模板增加“历史位置/被什么工作继承”和“证据等级”；
3. 在 `docs/design-synthesis.md` 的关键设计主张后链接代表论文与反证；
4. 新增一个年度/专题矩阵，而不是建立图数据库；
5. 每季度删除或降级对个人主线没有产生作用的条目。

暂不增加：引用次数自动排名、embedding 检索、复杂 ontology、自动生成引用图。当前 42 篇规模用 CSV 与 Markdown 足够。

## 7. 质量门槛

历史回填比每日摄入更容易产生“熟悉所以不核验”的错误，必须执行：

- 只从规范论文页、正式出版页、官方代码/项目页填写事实；
- 区分初次发表时间与最新修订时间；
- 摘要不复制 abstract，不凭二手综述补实验数字；
- 记录代码是否仍可运行、数据是否可得，而不只记录曾经公开；
- 社会模拟结论明确区分模型内涌现、人类相似性和现实预测；
- 对经典论文也记录失败模式和今天已知的局限；
- 每批至少抽查两条 ID、作者、版本、链接和索引字段。

## 8. 成功指标

三轮回填后，仓库应达到：

- 2022 年及以前不再为零，2018–2024 年形成连续谱系；
- `design-synthesis.md` 每个核心部件都有基础文献、近期方法和反证；
- 任一 2026 年核心条目都能回答“它相对哪个历史基线新增了什么”；
- 论文数量增长有限，但主题间的可解释连接明显增加；
- 能从仓库直接导出 text world model 的最小实验：环境、状态、角色、记忆、扩散、事件、重放与评测。

## 9. 下一步
